# INARI 상점 영상 분석 (2026-11-24)

사용자가 준 스팀 상점 영상(2.88초, 868x290, 약 36fps)을 `scripts/video_probe.js`로 프레임마다 재고, 값이 튀는 시각의 프레임을
크게 보며 적은 것이다. 수치는 그 스크립트의 기준(흰색 = 밝기 215 초과, 어두움 = 24 미만, 붉은색 = r>150·g<90·b<110)으로 잰 값이라
다시 재면 같은 값이 나온다. 영상의 프레임은 저장소에 두지 않는다(타인의 저작물). 여기에는 수치와 관찰만 남긴다.

## 목차
1. 전체 수치
2. 시간표 (무슨 일이 언제)
3. 처형 0.4초를 프레임 단위로
4. 장면별 관찰 (모양·색·움직임)
5. 우리 게임에 옮길 때의 환산

## 1. 전체 수치

| 항목 | 값 | 뜻 |
|---|---|---|
| 완전히 같은 프레임 | 0장 | 화면 정지(히트스톱)를 쓰지 않는다. 느려질 뿐이다 |
| 평소 평균 밝기 | 약 30/255 | 배경이 어둡다. 그래서 색 면과 흰색이 뜬다 |
| 평소 어두운 픽셀 비율 | 45~49% | |
| 처형 직전 어두운 픽셀 비율 | 59~61% (1.8 → 2.1초, 약 0.3초에 걸쳐) | 배경만 어두워지고 캐릭터와 이펙트는 그대로 |
| 평타의 색 면 | 화면의 3~5%, 2~3프레임(약 0.08초) | 짧고 진하다 |
| 대시 관통 순간 | 평균 밝기 59.5 (흰색 5.7%, 붉은색 5.2%) | 한 프레임에 밝기가 한 배 반 |
| 처형 원반 프레임 | 붉은색 11~12%, 흰색 약 2% | 색 면이 흰색의 6배 |
| 흰 빛줄기 프레임 | 평균 밝기 54~57, 각 한 장 | 가장 밝은 장면은 한 장뿐 |

## 4. 장면별 관찰

**초승달.** 가운데가 두껍고 끝이 가는 진한 색 면. 바깥 가장자리에만 가는 밝은 테두리, 안쪽 가장자리는 톱니처럼 들쭉날쭉하다.
꼬리 끝은 붓끝처럼 두세 갈래로 갈라진다. 흰색은 테두리와 끝의 반짝임뿐이다.

**가로 줄.** 빠르게 옆으로 움직인 것(대시한 몸, 가로 베기)의 뒤쪽 가장자리는 가로로 긴 픽셀 줄들로 찢겨 있다. 줄 길이가 제각각이고
몇 줄은 본체에서 떨어져 있다. 속도감은 여기서 나온다.

**별빛.** 베기가 지나간 자리에 1~3px 크기의 흰 십자가 몇 개 남아 0.2~0.3초에 걸쳐 커졌다 작아진다. 많지 않다(한 번에 3~6개).

**연기.** 대시 출발과 착지에 부드럽고 반투명한 회색 연기. 픽셀이 굵지만 가장자리가 흐리다.

**불꽃 궤적.** 대시가 지난 바닥에 붉은 불꽃이 띠처럼 남는다. 가운데에 가는 흰 선, 불꽃은 위로 혀처럼 솟고, 진행 방향 앞쪽으로
점선이 이어진다. 0.3~0.6초 유지.

**표식.** 관통할 때마다 적 머리 위에 붉은 네 갈래 별이 하나씩 늘고(1 → 3), 몸에 금빛 마름모 조준이 걸린다. 다 차면 적에게 붉은 테두리.

**고리.** 큰 타격마다 가는 흰 고리가 화면의 절반 가까이까지 빠르게 퍼진다. 두께는 1~2px, 군데군데 끊어져 있다.

**처형의 원반.** 완전한 원이 아니라 가장자리가 부드럽게 빛나는 진한 붉은 덩어리. 주변에 같은 색의 빛 번짐이 넓게 깔린다.
가운데에는 작은 흰 여덟 갈래 별 하나.

**색 번짐.** 처형 동안 바닥의 가로 선과 주인공 실루엣 가장자리가 빨강·초록·파랑으로 갈라진다. 화면 가장자리로 갈수록 크게 갈라지고,
갈라지는 폭은 화면 높이의 1.5~2%.

**카메라.** 대시를 빠르게 따라간다. 흔들림은 작고 짧다.

## 5. 우리 게임에 옮길 때의 환산

- 영상은 약 36fps, 우리 시트는 30fps로 굽는다. "한 프레임"은 우리에게도 한 프레임(0.033초)으로 옮긴다. 처형처럼 느려진 구간은
  실제 시간으로 재생한다(SKILL.md 4절).
- 영상 높이 290px 기준의 길이는 우리 화면(1080) 기준 약 3.7배. 예: 색 번짐 5px → 약 18px.
- 영상의 주인공 색(붉은색·자홍)은 우리 게임에서는 게이지 구간 색으로 바뀐다. 위험 구간(90%+)만 레드다.
- 우리 색 층은 알파 0/255라 부드러운 연기·부드러운 원반 가장자리는 그대로 옮길 수 없다. 빛 층(`assets/light`)으로 번짐을 내고,
  색 층의 가장자리는 불규칙한 입자로 흐트러뜨린다.
