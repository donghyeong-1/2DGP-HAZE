# 헤이즈 (Haze)

2D 게임 프로그래밍 프로젝트(Python, pico2d). 게이지가 0%면 죽고 100%면 터진다. 그 사이를 지키며 싸우는 횡스크롤 액션 로그라이트.

운석이 떨어진 자리에 세운 격리 감옥 도시, 네뷸라 교도소. 흰 머리의 죄수 실험체 N-09가 최외곽 슬럼에서 공장을 지나 중앙의 감시자의 탑까지 뚫고 나간다.
쓰러지면 은신처로 돌아와 판을 처음부터 다시 시작한다. 판 안에서 얻은 증강과 무기는 사라지고, 헤이즈 결정으로 산 영구 강화는 남는다.

## 실행
```
pip install -r requirements.txt
python src/main.py
```
- 실행 파일(파이썬 없는 Windows PC용): `python -m pip install pyinstaller` 뒤 `python tools/build_exe.py`를 실행하면 `dist/Haze/Haze.exe`가 생긴다(폴더째 옮긴다). 나눠 줄 파일은 `dist/Haze_win64.zip`이다.
- 전체 판 자동 점검(오류·프레임 시간): `python tools/smoke_run.py --seeds 3`.
- 저장 파일은 홈 폴더에 생긴다. 영구 성장은 `~/.haze_save.json`, 설정은 `~/.haze_options.json`, 오류 기록은 `~/.haze_log.txt`.

## 판의 흐름
1. **은신처**: 정비사(기본 능력 영구 강화), 보관인(물건 하나를 다음 판으로), 기록관(이야기·기록), 무기 걸이(시작 무기 두 칸), 연습장. NPC들은 직전 판 결과에 따라 다른 말을 한다.
2. **제9구역: 폐기물 슬럼**: 끝은 관문 정예 전투.
3. **제4구역: 철골 공장**: 끝은 보스 크래셔.
4. **코어 구역: 감시자의 탑**: 총감시관 아크를 쓰러뜨리면 헤이즈 심장이 내려온다. 심장까지 부수면 탈출이다.

구역은 판마다 새로 만들어진다. 갈림길(짧은 길·긴 길), 물결 전투, 두 화면짜리 큰 방, 이벤트 방(헤이즈 샘·떠돌이 죄수), 도전방, 황금방·정비방·균열방, 구역별 장치(상자·증기 분출구·감시 레이저)가 있다.

## 헤이즈 게이지
| 구간 | 범위 | 효과 |
|---|---|---|
| 페이드 | 1~19% | 이동이 느려지고 공격이 약해진다. **0%가 되면 사망** |
| 노멀 | 20~49% | 기본 |
| 각성 | 50~89% | 공격력 x1.5, 속도 +25% |
| 위험 | 90~99% | 공격력 x1.8, 속도 +35% |
| 오버로드 | 100% | 체력 20% 피해, 1.5초 기절, 30%로 돌아온다 |

게이지는 시간이 지나면 줄고, 적을 치거나 처치하면 오르고, 맞으면 줄어든다. 적과 보스의 기술 중에는 게이지를 올리는 것과 내리는 것이 섞여 있다.

## 조작 (기본 키, 설정 > 키 바꾸기에서 변경)
| 키 | 동작 |
|---|---|
| A / D | 이동 |
| Space, W | 점프 (공중에서 한 번 더). 짧게 누르면 낮게 뛴다 |
| S + Space | 얇은 바닥 아래로 내려가기 |
| 마우스 좌클릭 | 마우스 방향으로 공격 (꾹 누르면 이어서) |
| 대시 중·직후 좌클릭 | 대시 공격: 앞으로 돌진하며 줄에 선 적을 모두 벤다 |
| 공중에서 좌클릭 | 점프 공격. 아래를 겨누면 내려찍기 |
| Shift, 마우스 우클릭 | 마우스 방향 대시 (무적, 슬롯 2개) |
| E | 게이지 25%를 써서 다음 공격 한 번을 강화한다. 거듭 누르면 2단계, 3단계는 **궁극기** |
| Tab, 1, 2 | 무기 교체. 바꾸는 순간 그 무기의 **교체기**가 나간다 |
| Q | 물약 마시기 |
| F | 상호작용 (NPC와 말하기, 진열대 획득·구매, 이벤트) |
| Esc | 일시정지 |
| F1 | 디버그 표시 (F3/F4 게이지 ±10, F5 적 재생성, H 피격) |

게임패드(Xbox 배치)도 된다. 왼쪽 스틱으로 이동, 오른쪽 스틱으로 조준하고, A 점프, B 대시, X 공격, RB 강화, LB 교체, Y 상호작용, Start 일시정지다.
설정의 테스트 모드를 켜면 무적이 되고 F6~F9로 구역·보스 바로가기를 쓸 수 있다(발표·점검용).

## 무기와 두 무기 조합
- 무기는 넷이고 장착 칸은 둘이다. 철파이프(3타 올려베기), 쌍권총(연사), 건틀릿(눌렀다 떼면 돌진 강타), 사슬(타격, 증강으로 끌어오기). 은신처 무기 걸이에서 두 칸을 고르고, 판 중에 주운 무기는 들고 있지 않은 칸과 바뀐다.
- **각인·격발**: 한 무기로 맞힌 적을 다른 무기로 치면 격발이 일어난다. 추가 피해에 더해 터뜨린 무기에 따라 효과가 다르다.
- **형태**: 구역의 첫 전투방 보상으로 무기의 땅 기본 공격을 다른 형태로 바꿀 수 있다.
- **증강**: 방을 클리어하면 카드 셋 중 하나를 고른다. 같은 갈래를 모으면 진화한다.

## 에셋 다시 만들기
타일·배경·이펙트·HUD·효과음·음악은 코드로 만든다. 외부에서 가져온 완성 에셋은 폰트뿐이다.
```
python tools/make_world.py     # 타일 세트·원경·중경
python tools/make_fx2.py       # 전투 이펙트 (--look <이름>으로 모아 보기)
python tools/make_hud.py       # HUD 조각
python tools/apply_ui_parts.py  # UI 부품 (Gemini G06 시트 -> assets/ui/uc_*.png)
python tools/make_sfx.py       # 효과음
python tools/make_music.py     # 배경음악
```
캐릭터 그림은 AI 이미지 생성(Codex·Gemini)으로 만들고, 프롬프트는 `docs/image_prompts.md`에 있다(`docs/codex/TASKS.md`, `docs/gemini/TASKS.md`). 출처와 라이선스는 `docs/ASSETS.md` 맨 위 표에 있다.
