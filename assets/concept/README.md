# 캐릭터 콘셉트 이미지

AI 이미지 생성 툴로 만든 이미지를 이 폴더에 아래 파일명으로 저장한다. 프롬프트는 `docs/image_prompts.md`를 사용한다.

| 파일명 | 대상 | 우선순위 |
|---|---|---|
| `n09.png` | 주인공 N-09 (흰 머리) | 1 (가장 먼저 만들어 화풍을 정함) |
| `boss_ark.png` | 최종 보스 총감시관 아크 | 2 |
| `enemy_slum.png` | 슬럼 폐인 | 3 |
| `enemy_thrower.png` | 고철 투척병 | 3 |
| `enemy_hound.png` | 안개 사냥개 | 3 |
| `enemy_guard.png` | 중장갑 간수 | 3 |
| `boss_crasher.png` | 제4구역장 크래셔 | 3 |

- 형식은 PNG, 배경은 투명이 가장 좋고 단색이어도 된다.
- 옆모습, 전신, 오른쪽을 보는 구도를 유지한다.
- 이미지를 만들 때마다 `docs/image_prompts.md`의 "생성 기록"과 `docs/ASSETS.md`에 도구명과 날짜를 적는다.
