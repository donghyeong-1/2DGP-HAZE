# UI 컨셉 셋 시안 PixelLab 생성 기록 (2026-11-26, docs/opus/TASKS.md '3차 변경')

교도소 철판 컨셉을 접고(사용자: "공사장 느낌", "감싸는 틀이 별로") 컨셉 셋을 시안으로 뽑았다.
그림(로고·틀·장식·표시)은 전부 PixelLab. 코드는 글자(게임 글꼴 Galmuri), 배치, 배경(게임 속 그림), 화면 효과(주사선, 어둡게 덮기)와
9칸 늘이기의 가운데 한 색 메우기만 한다. 갈래 아이콘 18개(`ui_plate_v1`)와 타이틀 배경(`backgrounds/title_plate.png`)은 셋 모두 그대로.

- 시안 화면: `python tools/ui_concepts_prep.py` (원본을 잘라 2배 조각 `<컨셉>/parts/`) -> `python tools/ui_concepts_shots.py <폴더>`
  (실제 창에서 그려 `A|B|C_title.png`, `A|B|C_cards.png`). 글자 크기·위치는 지금 `title_mode`·`mutation_mode`와 같다.
- 로고 셋: 'HAZE'를 PixelLab이 철자 그대로 쓰지 못할 수 있어, 굵은 도트 글자 모양만 기준 그림으로 올리고
  (`base/haze_letters_*.png`, 흰 꽉 찬 글자, 코드로 만든 기준) `edit_image_pro_flash`로 질감을 입혔다.
- 사용 횟수: 136회 (남은 횟수 916.7 -> 780.7).

## A 안개 미니멀 (a_mist/)
| 그림 | 도구·크기 | 프롬프트 요지 | 고른 것 |
|---|---|---|---|
| 로고 | edit_image_pro_flash 240x64 (seed 5) / 256x96 (seed 8) | 흰 글자의 오른쪽·위 가장자리가 청록 안개 줄기와 네모 알갱이로 풀려 흩어짐 | **s8** (s5는 안개가 거의 없었다. 여백 있는 256x96 바탕으로 다시) |
| 불씨 표시 | create_image_pro_flash 32x32 (seed 7), 청록 팔레트, 아이콘 화풍 기준 | 작은 헤이즈 불씨, 네모 알갱이 둘 | s7 |
| 카드 장식선 넷 | create_image_pro_flash 128x16 (seed 9), 흰·청록·금·빨강 팔레트 각각 | 가운데 마름모, 양끝이 점으로 흩어지는 가는 선 | s9 넷 (흰색 s7은 너무 어두워 다시) |
| 고른 카드 아래 안개 | create_image_pro_flash 128x32 (seed 9) | 점묘로 흩어지는 낮은 청록 안개 웅덩이 | s9 |

## B 감시 단말 (b_terminal/)
| 그림 | 도구·크기 | 프롬프트 요지 | 비고 |
|---|---|---|---|
| 로고 | edit_image_pro_flash 240x64 (seed 5) | 낡은 CRT 감시 모니터의 인광 글자, 주사선 틈, 빨강·파랑 색 어긋남 | 그대로 씀 |
