# UI 'mist' 스킨 PixelLab 생성 기록 (2026-11-27, docs/opus/TASKS.md '3차 변경 2')

사용자가 컨셉을 골랐다: 타이틀 = B 감시 단말, 증강 선택 = A 안개 미니멀. 증강 카드에 "그래도 테두리 정도는 있어야" 해서
가는 테두리 하나를 새로 만들었다. 나머지 그림(B 로고·커서·표시등·꺾쇠, A 장식선·안개)은 `../ui_concepts_v2/`의 시안 그림을 그대로 쓴다.
굽기: `python tools/make_ui_mist.py` -> `assets/ui/um_*.png`, `assets/light/title_shade.png`(코드로 구운 어둠, PixelLab 아님).

| 그림 | 도구·크기 | 프롬프트 요지 | 결과 |
|---|---|---|---|
| 카드 테두리 | create_image_pro_flash 128x176 (seed 21, 22), 팔레트 #eef1f5 #b8c0cc #6e7888 #343c4a, 화풍 기준 = A 흰 장식선(`divider_white_s9.png`) | 한 줄 가는 회백 선의 세로 사각형, 위·아래 변 가운데 작은 마름모, 네 모서리 짧은 마디, 속·바깥 투명, 금속·리벳·두꺼운 틀 없음 | **s22** (`raw/frame_white_s22.png`). s21은 속에 흰 얼룩이 생겼다. s22는 도트 2px로 와서(2x2의 90%) 반으로 줄여 도트 1칸 선으로 썼다 |

- 등급 색(진화 청록·합성 금·저주 빨강)은 s22의 밝기 단계 넷을 A 장식선(PixelLab)의 색으로 바꿔 끼웠다. 모양은 넷이 같다. 고른 카드(_hot)는 한 단계씩 밝게.
- 변은 모서리 바로 안쪽 한 줄을 이어 붙였다(가운데 마름모 자리에는 A 장식선이 얹힌다).
- 사용 횟수: 12회 (남은 횟수 780.7 -> 768.7).
