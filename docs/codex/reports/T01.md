## 기준과 달라 보이는 점
- 머리·얼굴·눈: 머리 실루엣이 더 크고 각지며 눈에 비해 코·입은 작다.
- 의상: 신발이 끈 달린 장화이고 청록 밴드와 허리끈이 기준보다 선명하다.
- 비율·크기: 123px 키, 너비 40px. 기존 이미지 81px, v2 82px보다 크다.
- 색·음영: 밝은 청록 림라이트가 기준보다 두드러지고 옷은 넓은 그림자 색면으로 표현됨.

## 해결하지 못한 문제
- 1배에서 눈 하이라이트 및 개별 손가락 가독성이 부족하다. 수치 검사 통과가 전체 합격을 뜻하지 않는다.
- `python tests/test_pixel_assets.py`: `test_tiles_are_multiples_of_tile_size` 실패. `src/config.py`의 TILE=60인데 기존 `tile_oneway.png`는 40×40이다. 타일과 코드는 작업 범위 밖이라 수정하지 않았다.
- 각 캐릭터 공통 팔레트 일치는 검증하지 않았다. 게임 내 1배 확인은 하지 않았다.

## 사용한 도구
- generate2dsprite `--finish hibit`, Codex 내장 image_gen (`host-image_gen`, 모델명 미제공, 비용 미제공), `tools/finish_character.py`, `tools/check_sprites.py`.
- 원화는 1장 생성, 마스터 정규화 경고 없음. 픽셀 마감 QA 경고·실패 없음, 육안 확인 대기 상태.

### 기준과 달라 보이는 점과 남은 사항

- 흰 앞머리가 위로 올라갔고, 흰자가 없는 큰 청록 눈이라 v3보다 표정이 단순하고 눈이 도드라진다. 피부는 따뜻한 살색 계열로 정리됐다. 원화에 두 톤을 요청했으나 마감 팔레트에는 유사한 살색 다섯 값이 남았다.
- 불투명 영역은 v3와 같은 40×123px이다. 손은 주먹으로 단순화했고, 장화 끈은 1배에서 v3보다 흐리다. 뒤쪽 림라이트는 드문 작은 색면으로 보인다.
- 생성 원본은 1254×1254px로 반환됐다. Forge로 규격화한 마스터는 1024×1024px이다.
