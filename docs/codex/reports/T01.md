## 기준과 달라 보이는 점
- 머리·얼굴·눈: 머리 실루엣이 더 크고 각지며 눈에 비해 코·입은 작다.
- 의상: 신발이 끈 달린 장화이고 청록 밴드와 허리끈이 기준보다 선명하다.
- 비율·크기: 123px 키, 너비 40px. 기존 이미지 81px, v2 82px보다 크다.
- 색·음영: 밝은 청록 림라이트가 기준보다 두드러지고 옷은 넓은 그림자 색면으로 표현됨.

## 해결하지 못한 문제
- 1배에서 눈 하이라이트 및 개별 손가락 가독성이 부족하다. 수치 검사 통과가 전체 합격을 뜻하지 않는다.
- `python tests/test_pixel_assets.py`: `test_tiles_are_multiples_of_tile_size` 실패. `src/config.py`의 TILE=60인데 기존 `tile_oneway.png`는 40×40이다. 타일과 코드는 작업 범위 밖이라 수정하지 않았다.
- 각 캐릭터 공통 팔레트 일치는 검증하지 않았다. 게임 내 1배 확인은 하지 않았다.
