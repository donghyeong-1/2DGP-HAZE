# T01 검토 결과 (Claude Code, 2026-11-11)

판정: **재작업 (v3b)**. 몸·옷·신발은 합격 수준이지만 얼굴과 림라이트에 문제가 있다.

## 측정
- `check_sprites.py` 통과: 키 123px, 반투명 0, 색 40, 내용 너비 40px.
- Codex 보고서의 자체 평가(눈 하이라이트·손가락 미달)는 정확하다. 정직하게 적어 줘서 고맙다.

## 좋아진 점 (유지할 것)
- 체형이 넓어지고 팔 근육 윤곽, 찢어진 소매와 바짓단, 끈 달린 장화와 밑창, 팔 밴드 줄 무늬, 허리끈 매듭이 1배에서 구분된다.
- 머리카락 덩어리가 더 크고 뾰족하다. 기존 인물로 알아볼 수 있다.

## 고칠 점 (1배에서 10배 확대로 확인)
1. **얼굴이 읽히지 않는다.** 눈이 어두운 덩어리 3px와 아래 청록 1px뿐이고 앞머리가 눈 위를 덮는다. 홍채 하이라이트 없음. 기존 임시본(v2를 123px로 마무리한 것)이 오히려 눈이 더 또렷하다.
2. **피부 색이 지저분하다.** 뺨·목에 분홍·보라 줄무늬가 있어 멍이나 노이즈처럼 보인다. 입은 보라색 덩어리로 보인다.
3. **림라이트가 얼굴·머리에도 들어갔다.** 이마 앞 가장자리에 청록 점이 흩어져 있고, 몸 뒤쪽에는 청록선이 실루엣을 따라 이어져 네온 외곽선처럼 보인다. 이 게임은 외곽선을 1px 짙은 남색으로 통일했으므로 얼굴·머리·피부의 림라이트는 없애야 한다.
4. 손은 덩어리라 손가락이 구분되지 않는다 (키 123px에서는 손가락 5개를 모두 보이게 하는 것이 무리다).

## 재작업 지침 (T01_hero_v3.md 맨 아래 "재작업 v3b"에 반영함)
- 눈을 크게(눈 전체 폭이 머리 폭의 20% 이상), 앞머리는 눈 위로 내려오지 않게 옆으로 쓸어 올린다.
- 피부는 2톤만 (살색 + 한 단계 어두운 살색). 분홍·보라·붉은 그림자 금지. 입은 어두운 갈색 선 한 줄.
- 림라이트는 옷·팔·다리·신발의 뒤쪽 가장자리에만, 얇게. 얼굴·머리카락·피부에는 쓰지 않는다.
- 손은 주먹 쥔 모양 또는 엄지만 분리된 덩어리로 단순화한다 (손가락 5개 요구는 철회).
- 몸·옷·신발·팔 밴드 디테일은 v3 그대로 유지한다.
