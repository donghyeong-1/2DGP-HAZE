## 시도 기록

1회 생성. 기존 진열대·감방 타일과 캐릭터의 팔레트를 `reference_1x.png`에 모았다. 3열×2행 마젠타 시트 한 장에 황동·청색 금속 진열대, 빨간 잠금등과 빗장, 청록 조명의 열린 통로를 요청했다. 원화는 `source.png`, 프롬프트 전문은 `actual_prompt.txt`에 있다.

`generate2dsprite process --strict-qc`로 배경 키잉과 6개 셀 분리를 완료했다. 시트 경계에서 `safe_frame` 경고가 6셀에 발생했으며, 여섯 형상은 각 셀에 온전히 남았다. 원화의 가로세로 비율을 캔버스에 맞춘 뒤 `finish_character.py`가 호출하는 동일한 hibit 도구를 직접 실행했다. 공통 24색 팔레트를 주고, 마감 후 크기를 바꾸지 않은 채 진열대는 바닥에, 문은 가운데에 배치했다. 마감 경고 `pixel-reduction`은 원화와 출력의 픽셀 비율이 2.552~3.190으로 도구 기준 4보다 낮아서 발생했다. 일부 중간 폴더의 저장 단계에서 Windows 파일 이동 오류가 발생해 같은 원화로 마감 저장을 재시도했다. 확인 수치는 `qa_props.json`에 있다.

## 검사

- 캔버스 크기와 알파 0/255, 색 수 제한, 공통 팔레트, 외곽선 색, 진열대 바닥선을 확인했다. 기존 게임의 아이콘 오프셋에 해당하는 48×48 영역은 두 진열대 모두 비어 있다. 잠긴 문 중심은 불투명하고 두 열린 문 중심은 투명하다.
- 기존 황금방·정비방 배경과 T13 아이콘을 합성한 1배 확인판에서 진열대 상태 세 가지, 문 상태 세 가지를 확인했다.
- `python tests/test_pixel_assets.py` 8개 통과. Pillow의 `getdata` 사용 중단 예정 경고가 표시됐다.

## 기준과 달라 보이는 점

- 가져간 뒤의 제단은 밝은 황동 제단과 바닥선·폭·높이가 같다. 원화에서 윗부분 기울기가 조금 달라지고, 얇은 황동 테두리가 남았다.
- 청색 선반의 가격표를 작은 밝은 판으로 표현했다. 세로 문과 가로 해치 안쪽은 투명해 사용하는 방의 배경이 드러난다.

## 남은 확인

- 실제 게임에 넣었을 때 문틀의 2~5px 투명 여백이 인접 타일 사이에 눈에 띄는 틈을 만드는지 확인해야 한다.
