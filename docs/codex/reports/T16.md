## 시도 기록

| 회차 | 변경과 결과 |

| 1 | 마스터의 흰 머리와 청록 밴드·허리끈, 엔딩의 격리 도시, 감시자의 탑의 남색 기조를 참조했다. 왼쪽 아래 외벽 위의 N-09, 오른쪽의 탑과 푸른 결정, 가운데의 짙은 하늘을 얻었다. N-09의 높이는 약 39%였다. |

각 회차 프롬프트는 `title/prompt_01.txt`부터 `prompt_03.txt`에 있다. 최종 원화는 `title/source.png`다. 1672×941 원화에 `conform_background.py conform --mode cover --size 1920x1080 --resampler lanczos`를 사용했다. 이 단계에서 원화가 약 1.1483배 보간됐다. `hibit_plate.py plate --size 1920x1080 --colors 32 --smooth 0 --preview-scale 1`로 화면 크기에 직접 양자화해 완성 도트판은 1배로 사용한다.

## 검사

- Pillow 확인 결과 1920×1080, 고유색 32개, 투명·반투명 0픽셀이다. `python tests/test_pixel_assets.py` 8개 통과. 기존 검사 코드에서 Pillow `getdata` 사용 중단 예정 경고가 표시됐다.
- Forge 마감 경고 `reduction: 1.0 (threshold 2.0)`. 마감 입력과 출력이 모두 1920×1080이라 한 출력 픽셀의 다수결을 위해 비교할 입력 픽셀이 충분하지 않다. 자세한 검사 수치는 `title/qa_title.json`과 `title/hibit/plate.json`에 있다.
- 작업 파일의 로고 설명은 320×96이지만 현재 `assets/ui/logo.png`는 480×144다. 미리보기에는 현재 파일을 1배로 사용했다. `title_mode.py`의 좌표와 색을 가져오고 게임과 같은 SDL_ttf로 갈무리 28/22px 글자를 렌더링했다. 미리보기는 오프라인 합성이다.
- 상단 로고와 슬로건은 인물·탑과 겹치지 않는다. 로고 밝은 면의 최소 대비는 4.89:1, 슬로건은 7.55:1, 시작 안내는 4.60:1이다. 하단 조작 안내의 최소 대비는 2.25:1이다. 문구 색과 해당 문구 바운딩 박스 안 배경의 상대 휘도를 비교했다.

## 남은 확인

- 하단 조작 안내 일부가 감시탑과 벽의 밝은 면에 걸려, 시작 안내보다 흐리게 보인다. 실제 게임 화면에서 해당 줄을 확인해야 한다.
- 원화의 짙은 안개 일부가 양자화 후 여러 남색 띠로 보인다.
