## 예고 자세 검토

- 탄막은 가슴 앞에 먼 손바닥을 들고 선 자세다.
- 베기는 가까운 손날을 반대쪽 어깨 위로 크게 당긴 자세다.
- 흡수는 양손이 몸 양옆으로 멀리 벌어지고 가슴과 고개가 들린 자세다.
- 과충전은 두 팔을 얼굴 앞에서 교차하고 낮게 웅크린 자세다.
- 장판은 한쪽 무릎을 꿇고 한 손을 머리 위로 든 자세다.

다섯 장을 1배에서 확인했다. 흡수와 과충전의 벌림·웅크림이 반대로 읽힌다. 탄막과 베기는 모두 서 있지만 손의 높이와 팔 위치가 다르다. 탄환·칼날·파동·장판·빛줄기를 원화에 넣지 않았다. 순간이동 사라짐 한 장은 요구한 불투명 청록·검은 조각을 포함한다.

## 시도 기록

| 시트 | 생성 | 처리와 확인 |

| B | 1회 | 3열×3행을 9칸으로 분리했다. 서 있는 기준 높이와 허리 x를 등록해 5종 동작으로 마감했다. |
| C | 1회 | 가로 원화의 쓰러진 자세가 오른쪽 두 칸에 걸쳐 넓게 그려졌다. 인물 사이 빈 공간 x=400·840으로 소유 영역을 나누어 세 인물을 온전히 분리하고 공통 크기 칸으로 재배치했다. 페이즈와 사망으로 나누어 마감했다. |

원화 총 3회 생성, 재생성 0회다. 캐릭터는 지정된 아크 마스터와 게임 대기 그림을 참조했다. 순수 마젠타를 키잉하고 원화 단계에서 마스터의 서 있는 해부학적 크기에 맞춘 뒤 `tools/finish_character.py --like remake_t01_t03/finished/boss_ark_remake`를 실행했다. 서 있는 몸을 기준으로 잡아 무릎 꿇기·숙임·눕기의 낮아진 키를 유지했다. 마감 설정과 마스터의 팔레트는 그대로 재사용했다.

원화는 `ark_actions_v1/{A,B,C}/source.png`, 실제 프롬프트는 각 폴더의 `actual_prompt.txt`에 보관했다. 분리·등록·검토 작업 스크립트도 해당 작업 폴더 안에 있다.

## 검사

- 완성 PNG 23장 모두 알파 0 또는 255, 동작별 39~41색이며 아크 기존 팔레트와 외곽선 색 안에 있다.
- 프레임의 잘림·빈 이미지를 확인했다. 세 시트의 `process --strict-qc`가 모두 통과했다.
- 마감기의 전체 상태는 `needs-visual-review`다. 수치 항목은 pass 또는 skipped였고, 경고·실패는 없었다. 전체 1배 확인판에서 23장을 모두 확인했다.
- 대기·걷기는 159px이고 걷기 네 프레임의 밑창 경계는 y=160으로 같다. 허리 버클 주변 밝은 회색의 중앙값 x는 59.5·63.5·63·62px로 중간값 61.5px 대비 ±2px다. 원화의 같은 허리 기준을 고정해 등록했다.
- 각 동작 안에서 밑창 경계가 같다. 서로 다른 동작도 각 `finish.json`의 기준점에 맞춰 놓으면 같은 바닥선이 된다. 사망 2번은 발이 뒤로 뻗은 누운 자세라 몸의 아래 경계를 사용했다.
- 12개 GIF의 프레임 수·순서·표시 시간과 원본 PNG의 픽셀을 디코딩해서 비교했다. 각 GIF의 배경만 검토용 단색으로 합성했다.
- GIF 예고는 작업서의 탄막 600ms, 베기 450ms, 흡수·과충전 900ms, 장판 700ms를 사용했다. 실행·회수 시간과 이동·연출 GIF 시간은 검토용으로 정한 값이며 `provenance.json`에 기록했다.
- `python -B tests/test_pixel_assets.py` 8개 통과. 기존 검사 코드의 Pillow `getdata` 사용 중단 예정 경고 2건이 있다.

공격·사망의 의도적인 자세 변화는 기본 키 차이 검사에서 실패한다. 해당 묶음은 `--air`로 알파·팔레트를 검사하고 바닥선을 별도로 확인했다. 등장 141px, 피격 155px, 주먹을 높이 든 페이즈 176px는 159px의 서 있는 키와 달라, 그 자세의 측정 높이를 명시한 보조 검사를 했다. 이 보조 검사는 해부학적 비율을 자동으로 증명하지 않으므로 마스터와 1배 확인판도 함께 비교했다.

## 기준과 달라 보이는 점

- 머리·얼굴·눈: 검은 머리, 군모, 눈과 차가운 옆얼굴이 1배에서 읽힌다. 고개를 숙인 과충전·장판·사망에서는 눈이 모자와 팔에 가려진다.
- 의상: 긴 검은 코트, 은색 테두리, 청록 안감·가슴 수정이 유지된다. 새 대기는 마스터보다 코트 자락이 넓고, 대기 두 장의 코트 너비 변화가 숨쉬기보다 눈에 띈다.
- 비율·크기: 대기와 걷기는 마스터와 같은 159px다. 반듯하게 섰을 때의 가슴·허리 덩어리를 비교했고, 숙이고 무릎 꿇는 동작은 몸을 낮춘 크기를 유지했다. 베기 3번은 몸이 많이 숙여지고 앞으로 실린다.
- 색·음영: 동일 팔레트를 사용했다. 코트 아래 가려진 먼 쪽 다리의 명암 구분은 약하고, 걷기 2·4번의 무릎 들림이 높아 느린 위압적 걸음으로 사용할 때 체감 검토가 필요하다.

## 해결하지 못한 문제

실제 게임 이동과 공격 이펙트에 연결한 연속 재생은 적용 후 검토할 항목이다. 특히 코트 아래 지지발 교대가 약하게 읽히는 부분과 대기 자락 움직임의 크기를 보고했다. 원화 세 시트와 23장 중 빠진 동작은 없다.

## 사용한 도구

- 설치된 generate2dsprite 0.5.0, Codex 내장 image_gen(호스트 경로, 모델명·비용 미제공), 프로젝트 hibit 마감·검사 도구, Pillow 13.0.0.
- [forge_doctor](../../../assets/sprites/forge/ark_actions_v1/doctor.json)에서 호스트 이미지 경로를 확인했다. `python.path` 경고는 PATH의 다른 Python 실행 파일에 대한 진단이다. 실제 처리는 Python 3.12.10으로 실행했다.
