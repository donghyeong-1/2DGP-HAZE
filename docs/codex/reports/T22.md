## 장면과 인물 확인

원경은 따뜻한 주황 등불과 청록 결정 조명, 작업대·소파·지도·사물함·매달린 전선으로 안전한 아지트를 표현했다. 가운데에는 벽과 낮은 대비의 배관만 두고 소품을 양끝으로 보냈다. 글자는 없다. y=810~1080은 어두운 그림자 두 색(#131D28, #24262A)으로만 구성된다. 투명 픽셀은 0개다.

정비사는 넓은 체형의 중년 여성, 이마의 용접 고글, 올리브색 작업복, 어깨의 큰 렌치와 청록 결정 의수로 표현했다. 보관인은 마른 노인, 후드 코트, 등에 멘 큰 자물쇠 상자와 손의 등불이다. 기록관은 짧은 갈색 머리의 젊은 인물로 안경·연필·수인표와 두꺼운 장부를 들었다. 1배에서 세 실루엣과 렌치·상자·책이 서로 구별된다. 인물과 바닥선은 원경 배치 미리보기에서도 1배로 확인했다. 미리보기의 x 위치와 바닥 y=810은 검토용 배치다.

## 시도 기록

| 순서 | 생성 횟수 | 처리 |
|---|---:|---|
| 원경 | 1 | generate2dmap 방식으로 생성, conform_background → hibit_plate로 마감 |
| 정비사 | 마스터 1 + 대기 시트 1 | 마스터 126px 확인 후 같은 인물의 대기 두 장 생성·마감 |
| 보관인 | 마스터 1 + 대기 시트 1 | 마스터 117px 확인 후 대기 두 장 생성·마감 |
| 기록관 | 마스터 1 + 대기 시트 1 | 마스터 111px 확인 후 대기 두 장 생성·마감 |

Codex 내장 image_gen으로 총 7회 생성했다. 재생성은 없다. NPC는 주인공 v3b를 화풍 참조로 만들고, 각 마스터를 배경 제거·공통 프레이밍한 뒤 눈·소품·비율을 확인했다. 대기 시트는 해당 인물의 마스터를 직접 참조했다.

NPC 마스터는 `tools/finish_character.py --height 126/117/111`로 마감했다. 대기는 마스터의 실제 축소 비율과 팔레트를 `--like npc_<역할>_master`로 재사용했다. 바닥과 신발을 고정하고 상체만 약 1px 올라가도록 원화를 등록했으며, 완성 픽셀은 정수 이동과 투명 여백만 적용했다. 세 NPC 모두 1번 대비 2번의 최고점이 1px 높다.

## 검사와 경고

- NPC 여섯 장 모두 반투명 0개, 각각의 기준 마스터 팔레트와 외곽선 색 안에 있다. 각자 단일 키 검사와 두 장 묶음 검사 모두 통과했다.
- 대기 두 장의 얼굴·옷·크기와 같은 바닥선을 1배에서 확인했다. 렌치 머리, 큰 자물쇠, 책 덩어리와 안경이 보인다.
- 세 대기 시트의 `process --strict-qc` 모두 통과했다. NPC 마감 QA 수치 항목에 경고·실패가 없었고 전체 상태 `needs-visual-review`에 따라 여섯 장을 직접 확인했다.
- 원경 원화는 요청한 크기보다 작은 1672×941로 반환됐다. T06과 같은 처리로 원화 단계에서 `conform_background.py`가 **1.148325359배** 보간해 1920×1080으로 맞춘 뒤, `hibit_plate.py --size 1920x1080 --colors 32 --smooth 0 --preview-scale 1`로 최종 픽셀판을 만들었다. 완성한 픽셀판은 1배다.
- 원경 마감의 QA 경고는 `reduction: 1.0 (threshold 2.0)`이며 파일은 `hideout_v1/hibit/plate.json`이다. 마감 입력과 출력이 같은 크기라 한 최종 픽셀을 여러 원화 픽셀의 다수결로 결정할 여지가 적다. 얇은 사선과 빛 경계에 잔 점이 보이는 한계가 남는다. 크기·32색·불투명 검사는 통과했다. 고립 픽셀 비율 정보는 0.00052다.
- `python -B tests/test_pixel_assets.py` 8개 통과. 기존 검사 코드에서 Pillow `getdata` 사용 중단 예정 경고 2건이 나온다.

## 기준과 달라 보이는 점

- 머리·얼굴·눈: 세 NPC 모두 1배에서 눈과 얼굴 방향이 읽힌다. 정비사는 고글, 보관인은 후드·수염, 기록관은 안경으로 구별된다. 기록관의 작은 연필과 목걸이 점은 가까이 볼 때 더 잘 보인다.
- 의상·소품: 주인공과 같은 각진 색면·어두운 외곽선을 사용했다. 정비사의 올리브 작업복과 녹색·주황 패치, 보관인의 갈색 상자·코트, 기록관의 회색 재킷과 적갈색 장부는 역할에 맞춰 새로 디자인했다.
- 비율·크기: 정비사는 주인공보다 넓고, 보관인은 큰 등짐 때문에 가로로 넓다. 기록관은 작고 마른 실루엣이다. 첫 자세 키 126/117/111px, 흡기 자세는 각각 +1px다.
- 색·음영: NPC마다 마스터의 40색 팔레트와 외곽선 색을 재사용했다. 최종 사용 색은 NPC별 41·41·36색이다. 주인공보다 따뜻한 갈색·주황 비중이 높다.
- 원경: 넓은 벽면과 양끝 소품은 캐릭터와 겹치지 않지만, 큰 벽장·작업대와 캐릭터 사이 원근·크기 체감은 실제 로비 적용 후 확인할 항목이다.

## 해결하지 못한 문제

원경의 원화 크기 보정과 1:1 픽셀화 경고, 얇은 경계의 잔 점을 위에 기록했다. 실제 은신처 타일·상호작용 창과 함께 동작하는 화면은 적용 후 확인할 항목이다. 요청한 원경과 NPC 3명·대기 6장 중 빠진 항목은 없다.

## 사용한 도구

generate2dmap·generate2dsprite 0.5.0, Codex 내장 image_gen(호스트 경로, 모델명·비용 미제공), 프로젝트 finish_character.py·check_sprites.py, Pillow 13.0.0. [forge_doctor](../../../assets/sprites/forge/hideout_v1/doctor.json)에서 호스트 이미지 경로를 확인했다. PATH의 다른 Python 실행 파일 경고가 있었고 실제 처리는 Python 3.12.10으로 실행했다.
