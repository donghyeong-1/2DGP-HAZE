## 시도 기록

- 슬럼 → 공장 → 탑 → 은신처 순으로 한 장씩 생성했다. 각 테마의 원경과 타일을 참조해 3행에 소품, 4열에 동작 순서가 들어가는 3×4 마젠타 시트를 요청했다. 네 테마 모두 원화 1회다. 원화와 실제 프롬프트는 [provenance.json](../../../assets/sprites/forge/props_anim_v1/provenance.json)에 연결했다.
- `sheet_qc.py spill`과 `generate2dsprite process --strict-qc`에서 네 시트 모두 통과했다. 공장 시트는 첫 게시 때 Windows 폴더 이동 오류가 나서 같은 원화로 처리를 다시 실행했다.
- T14와 같은 hibit 도구로 공통 팔레트 32색과 남색 1px 외곽선을 적용했다. 배치 기준을 고정하고, 움직이지 않는 브래킷과 받침은 첫 컷을 이용해 색과 픽셀을 통일했다. 톱니·환풍기는 생성 원화에서 4회 대칭 회전부를 정리하고 마감 전에 4개 각도를 구웠다. 감시등은 빛 부분을 이진 알파 패턴으로 처리해 뒤의 배경이 일부 비친다. 결정은 역방향 중간 밝기를 두 번째 컷과 같게 맞춰 반복 경계의 밝기 변화를 줄였다. 최종 1배 이미지는 배치와 픽셀 보정에 다시 확대·축소하지 않았다.

## 검사

- 최종 PNG 48장, 반투명 픽셀 0개, 공통 불투명 색 32개. 캔버스의 긴 변은 103~158px. 종별 기준점, 화면 경계, 반복 지표와 모든 마감 경고는 [qa_props.json](../../../assets/sprites/forge/props_anim_v1/qa_props.json)에 있다.
- GIF 12개를 해독해 4컷·각 120ms·저장 순서와 PNG의 배경 합성 픽셀이 같음을 확인했다. RGBA 채널 하나라도 7을 넘게 바뀐 픽셀 수로 마지막→첫 컷을 다른 세 전환의 중앙값과 비교했다. 최종 비율은 0.31~1.02이며, 모든 이웃 컷에 실제 픽셀 변화가 있다. 이 지표는 변화량이고 방향이나 자연스러움은 1배에서 확인했다.
- `check_sprites.py` 기본 검사는 9종이 통과했다. 감시등(빛 끝 y 차이 3px), 모루(불똥 높이 차이 26px), 화로(불꽃 높이 차이 24px)는 기본 검사에서 실패했다. 세 설치점과 고정부는 따로 확인했으며 세 종의 알파·팔레트 재검사는 `--air`로 통과했다. [전체 check_sprites.py 출력](../../../assets/sprites/forge/props_anim_v1/check_sprites.txt)
- 마감 도구 `pixel-reduction`은 12종 모두 경고다. 원화 대 출력 비율을 소품별로 기록했으며, 실제 값은 1.911~2.854로 도구 기준 4.0 미만이다. QA 원문은 `source px per output px; pixel art comes from about 8-12x`다. 생성본을 더 크게 만들어 한 번 더 줄이는 대신 현재 원화에서 목표 1배 해상도로 마감했다.
- 서로 다른 소품을 한 캐릭터로 판단하는 초기 `sheet_qc.py frames` 검사에서 머리 비율·몸통 편차 등의 항목이 나왔다. 결과는 [슬럼](../../../assets/sprites/forge/props_anim_v1/cell/sheet_check/sheet-qc.json), [탑](../../../assets/sprites/forge/props_anim_v1/haze/sheet_check/sheet-qc.json), [은신처](../../../assets/sprites/forge/props_anim_v1/hideout/sheet_check/sheet-qc.json)에 남겼다. 최종 판정은 소품별 4컷을 사용했다.
- `python -B tests/test_pixel_assets.py` 8개 통과. 기존 테스트의 Pillow `getdata` 사용 중단 예정 경고가 표시됐다.

## 기준과 달라 보이는 점

- 같이 놓은 N-09의 머리와 옷이 먼저 읽힌다. 각 소품의 최고 sRGB 휘도는 75~142, N-09 대기에서 95백분위 휘도는 244다. 전구 유리와 불꽃은 주변 일부 타일 표면보다 밝다. 모루 받침과 기계의 외장은 어둡게 유지했다.
- 감시등의 반투명 느낌은 투명·불투명 도트의 배열로 표현했다. 가까이서 정지해 보면 점무늬가 보인다. 물방울은 낙하 중간 한 장에서 파문으로 이어져 낙하 속도가 빠르게 보인다.
- 배치·표시 순서·반복 재생은 게임 적용 단계에서 확인할 항목이다. 소품 12종 모두 검토용 파일을 준비했다.
