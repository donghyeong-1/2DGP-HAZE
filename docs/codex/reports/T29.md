## 시도 기록

| 순서 | 생성 횟수 | 프롬프트 요약 및 결과 |
|---|---:|---|
| 로고 | 1 | 기존 게임 로고의 넓은 공업용 글자와 청록 색면을 참조했다. `HAZE`와 `헤이즈` 철자가 정확하며 연무가 글자 획을 가리지 않는다 |
| 헤더 | 1 | 기존 제목 화면·컷인·N-09 마스터를 참조했다. 오른쪽에 철파이프와 부츠까지 들어가고 왼쪽에 로고 자리가 있다 |
| 메인 | 1 | 두 승인 마스터와 헤더를 참조했다. N-09의 흰 머리·철파이프, 아크의 모자·긴 코트·가슴 결정이 구별된다 |
| 작은 캡슐 | 1 | 헤더를 상반신 중심 배너로 다시 잡고 컷인의 얼굴을 참조했다. 얼굴과 청록 팔띠가 작아도 읽힌다 |
| 세로 캡슐 | 1 | 제목 화면의 탑을 기단에서 올려다본다. 계단 아래에 N-09를 놓았다 |
| 라이브러리 배경 | 1 | 세 스테이지 원경을 참조해 감방·철골 공장·탑을 하나의 풍경으로 연결했다. 첫 마감에서는 중앙 크롭이 결정 끝을 잘라, 원화에서 위쪽을 기준으로 가로 7.3%와 세로 7.4%를 덜어낸 구도로 다시 마감했다. 최종 안전 영역에 결정 끝까지 들어간다 |

원화는 6회 생성했다. 이미지별 원화·프롬프트·프로젝트 참조·해시는 [provenance.json](../../../assets/sprites/forge/store_art_v1/provenance.json)에서 확인할 수 있다. 작업 파일의 부제는 메타데이터에 기록했다. 로고의 문구는 영문·한글 제목 두 줄이다.

## 검사

- 최종 파일 여섯 장의 해상도, 파일당 38~48색, 블록 격자와 알파를 검증했다. 배경 5장의 알파는 255이며, 로고는 0 또는 255다. 로고의 실제 불투명 내용 영역은 1172×406이다. 배경 원화는 `hibit_plate`로 각 논리 해상도에 맞춰 줄였고, 로고는 알파를 0과 255로 정리한 뒤 팔레트를 제한했다. 최종 규격의 픽셀 블록은 출력 때 한 번 구웠다.
- 각 PNG의 `check_sprites.py` 개별 검사 6건 통과. [전체 출력](../../../assets/sprites/forge/store_art_v1/check_sprites.txt)
- `python -B tests/test_pixel_assets.py` 8개 통과. 마감 도구의 다섯 판은 `needs-visual-review`였고 수치 경고·실패가 없었다. 검토판에서 인물, 제목 자리, 중앙 크롭을 별도 확인했다.
- 로고의 상대 휘도 0.20 이상인 불투명 픽셀을 해당 위치 배경과 비교했다. 합성 검토판의 대비비 5백분위는 헤더 5.67:1, 메인 5.88:1, 작은 캡슐 5.80:1, 세로 5.49:1이다. 어두운 외곽선과 연무는 이 수치에서 제외했다.

## 기준과 달라 보이는 점

- N-09의 흰 머리, 어두운 눈매, 찢어진 검은 옷과 청록 팔띠를 유지했다. 작은 캡슐에서는 컷인의 눈빛을 따랐고 위쪽 머리카락 일부가 화면 경계에서 잘린다. 얼굴과 팔띠는 462×174에서 분명하다.
- 아크는 승인본의 모자와 회색 테두리의 긴 코트, 가슴 결정을 유지했다. 메인 그림에서 상대를 보도록 반대 방향으로 잡았다.
- 120×45 합성 시험에서 영문 `HAZE`는 읽히지만 한글 `헤이즈`는 작아진다. 세로·라이브러리 판에서는 4px 블록으로 계단 난간과 결정의 가는 부분이 굵어 보인다.
