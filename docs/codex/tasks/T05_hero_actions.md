# T05 주인공 대기·공격·피격·점프 프레임

먼저 `docs/codex/COMMON.md`를 읽고 그 규칙을 따른다. **앞 작업 T04가 `done`일 때만 시작한다.** T04에서 얼굴·옷이 유지되는 것이 확인된 방식을 그대로 쓴다.

## 목표
주인공의 나머지 동작 4가지를 T04와 같은 방식으로 만든다. 동작마다 시트 1장씩, 총 4장.

## 동작 (이름 / 프레임 / 설명)
| 이름 | 프레임 | 설명 |
|---|---|---|
| `n09_breathe_v3` | 4 (2×2) | 서서 숨 쉬는 대기. 가슴과 어깨가 아주 조금 오르내리고 머리카락·허리끈 끝이 살짝 흔들린다 |
| `n09_attack_v3` | 4 (2×2) | 오른팔을 뒤로 당겼다가 앞으로 크게 휘두르는 동작 (무기 없이 빈손. 무기는 따로 그린다). 몸은 앞으로 기울고 마지막 프레임에서 회복 |
| `n09_hurt_v3` | 2 (1×2 또는 2×2의 앞 2칸) | 맞고 뒤로 젖혀지는 동작, 눈을 질끈 감지 말고 크게 뜬 채 |
| `n09_jump_v3` | 4 (2×2) | ① 웅크림 ② 상승 ③ 정점(다리 접음) ④ 하강(다리 펴고 팔 벌림) |

## 요구사항
T04와 같다: 모든 칸에서 얼굴, 의상, 몸 크기가 같고 바닥선 기준이 같다. 점프는 공중 동작이라 바닥선이 올라가는 것은 허용하지만 **캐릭터 크기는 같아야** 한다.

## 절차 (동작마다 반복)
1. `$generate2dsprite` `asset` 대상으로 해당 모드(idle/attack/hurt/직접 설명한 sheet) 시트 생성. 저장: `assets/sprites/forge/<이름>/`.
2. `process`로 프레임 분리 → `frames_raw/`.
3. `python tools/finish_character.py assets/sprites/forge/<이름>/frames_raw <이름> --like n09_v3b`
4. `python tools/check_sprites.py assets/sprites/forge/<이름>/frames/*.png` 통과.
5. 네 동작이 끝나면 보고서 `docs/codex/reports/T05.md`, 상태 `review`.

## 합격 기준
- [ ] 동작마다 `check_sprites.py` 통과
- [ ] 각 strip 이미지가 해당 동작으로 읽힌다
- [ ] 얼굴·옷이 프레임마다 달라지지 않는다
- [ ] 보고서에 솔직하게 적었다
