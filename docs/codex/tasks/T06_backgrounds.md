# T06 배경판 3종 (감옥 복도, 철골 공장, 감시자의 탑)

먼저 `docs/codex/COMMON.md`를 읽고 그 규칙을 따른다. 이 작업은 **시험적**이다. `$generate2dmap`이 이 화면 크기와 도트 굵기를 지키는지 모르는 상태에서 시작한다.

## 목표
한 화면(1920×1080) 배경판 3장. 캐릭터와 타일이 눈에 띄도록 어둡고 채도가 낮으며, 한가운데 플레이 영역은 조용해야 한다.

## 요구사항
- 크기 **1920×1080**, 도트 굵기는 캐릭터와 같은 1px (큰 도트로 그리거나 늘리지 않는다).
- 색은 한 장당 **48색 이하**, 알파 없음(불투명 배경).
- 3단 깊이: 먼 배경(어둡고 흐릿한 큰 형태) / 중간(구조물) / 가까운 장식(가장자리 파이프·케이블·창살). 가운데 가로 60%는 단순하게.
- 공통 팔레트 방향: 짙은 남색~강철색 + 청록 포인트 조명. 플레이어가 입는 검정·흰색과 겹쳐 보이지 않게 배경 명도를 낮게.
- 장면: ① `bg_prison_corridor` 감옥 복도(철창, 긴 복도 원근, 희미한 푸른 조명) ② `bg_iron_factory` 철골 공장(철골 구조물, 컨베이어, 붉은 먼지 없이 푸른 증기) ③ `bg_warden_tower` 감시자의 탑(높은 홀, 청록 수정 조명, 유리 창)
- 글자·로고·사람·적을 그리지 않는다.

## 절차
1. `$generate2dmap`의 배경판(plate) 기능으로 `--finish hibit`에 맞는 방식을 써서 3장 생성. 저장: `assets/sprites/forge/backgrounds_v1/<이름>.png`.
2. 크기와 색 검사: 파이썬으로 크기(1920×1080), 색 수(48 이하)를 확인한다. `tools/check_sprites.py`는 스프라이트용이므로 쓰지 않는다.
3. 각 배경 위에 `assets/sprites/unified_legacy/n09_idle.png`와 `assets/tiles/tile_solid_a.png`를 1배로 얹은 확인 이미지를 `backgrounds_v1/preview_<이름>.png`로 저장한다 (캐릭터가 묻히지 않는지 본다).
4. 보고서 `docs/codex/reports/T06.md`, 상태 `review`.

## 합격 기준
- [ ] 3장 모두 1920×1080, 48색 이하
- [ ] 도트가 캐릭터와 같은 굵기로 보인다 (늘린 흔적 없음)
- [ ] 미리보기에서 캐릭터와 타일이 배경에 묻히지 않는다
- [ ] 보고서에 솔직하게 적었다

## 안 될 때
스킬이 이 크기를 지원하지 않거나 도트 굵기가 맞지 않으면 3번까지 시도하고 멈춘다. 어느 단계에서 왜 안 됐는지 보고서에 적는다. (그 경우 Claude Code가 `parallax_build` 같은 코드 생성 방식을 쓴다.)
