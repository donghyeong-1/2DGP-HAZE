# T13 아이템 아이콘 10종

먼저 `docs/codex/COMMON.md`를 읽고 그 규칙을 따른다. 이전 작업(T07~T11)과 같은 방식(시트 1장 → `process` → `finish_character.py` 또는 `hibit_plate.py` → 검사)을 쓴다.

## 배경
`src/items.py`의 아이템 9종과 헤이즈 조각(재화)의 아이콘이 필요하다. 지금은 진열대와 HUD가 색 사각형에 글자 한 자로 표시된다. (코드로 그린 임시판이 `assets/ui/`에 만들어질 예정이다. Codex 판이 합격하면 교체한다. 파일 이름은 같게 맞춘다.)

## 규격
- 각 아이콘 **48×48 PNG**, 투명 배경, 반투명 픽셀 0개, 색 16개 이하(공통 팔레트 `assets/sprites/forge/n09_v3b/palette.json`의 청록·회색·검정 계열 + 아이템 포인트 색 1개), 1px 어두운 외곽선.
- 한 번에 10장을 한 시트(5×2)로 만든 뒤 `process`로 분리하고, 48×48로 마무리한다 (확대·축소 없이 도트가 정수 격자가 되도록 원화를 키워서 그린다).
- 저장: `assets/sprites/forge/icons_v1/`, 최종 파일명 `icon_<id>.png`.

## 공통 요구사항
- 선 없는 평면 색면, 재질마다 밝음·기본·그림자 3단계, 빛은 왼쪽 위 (`COMMON.md` 4절). 같은 이미지는 최대 3번까지 시도하고 멈춘다.
- 동작마다 새 폴더에 저장한다(기존 폴더 덮어쓰기 금지). 실패한 시도와 어색한 점은 보고서에 숨기지 않는다.
- 아이콘·소품은 **1배로 봤을 때 읽히는 것**이 기준이다. 얇은 선과 작은 무늬는 키워서 그린다.
