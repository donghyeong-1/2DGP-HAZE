# T14 진열대·문·상호작용 소품

먼저 `docs/codex/COMMON.md`를 읽고 그 규칙을 따른다. 이전 작업(T07~T11)과 같은 방식(시트 1장 → `process` → `finish_character.py` 또는 `hibit_plate.py` → 검사)을 쓴다.

## 배경
황금방·정비방의 진열대와 방의 문은 지금 단색 사각형과 색 글자로 그려진다. (코드로 그린 임시판이 `assets/tiles/`와 `assets/ui/`에 만들어질 예정이다. Codex 판이 합격하면 교체한다.) 타일 한 칸은 60×60px이다.

## 입력
- 화풍·팔레트: `assets/tiles/tile_set_cell.png`(현재 타일 세트), 주인공 마스터 `assets/sprites/forge/hero_v3b/master/master_rgba.png`의 청록 포인트
- 방 분위기: `assets/backgrounds/bg_gold.png`(황동), `bg_shop.png`(청색)

## 그릴 것 (각 파일은 투명 배경 PNG, 반투명 0개, 색 24개 이하, 1px 어두운 외곽선)
| 파일 | 크기 | 설명 |
|---|---|---|
| `pedestal_gold.png` | 120×150 | **황금방 제단**: 황동 받침 위에 열린 상자 모양의 빛나는 보관함. 위에 아이콘(48×48)이 놓일 자리(받침 위 가운데)가 비어 있다 |
| `pedestal_shop.png` | 120×150 | **정비방 진열대**: 청색 금속 선반과 작은 가격표 걸이. 위에 아이콘이 놓일 자리가 비어 있다 |
| `pedestal_gone.png` | 120×150 | 가져간 뒤(품절) 빈 제단: 같은 모양인데 빛이 꺼지고 어둡다 |
| `door_locked.png` | 60×180 | 전투 중 잠긴 문 (세로 3칸): 붉은 경고등과 겹빗장 |
| `door_open_h.png` | 60×180 | 열린 좌우 문: 문틀과 빛이 새는 틈 |
| `door_open_v.png` | 180×60 | 열린 위·아래 문 (가로 3칸): 구멍과 사다리 힌트 |

## 공통 요구사항
- 선 없는 평면 색면, 재질마다 밝음·기본·그림자 3단계, 빛은 왼쪽 위 (`COMMON.md` 4절). 같은 이미지는 최대 3번까지 시도하고 멈춘다.
- 동작마다 새 폴더에 저장한다(기존 폴더 덮어쓰기 금지). 실패한 시도와 어색한 점은 보고서에 숨기지 않는다.
- 아이콘·소품은 **1배로 봤을 때 읽히는 것**이 기준이다. 얇은 선과 작은 무늬는 키워서 그린다.
