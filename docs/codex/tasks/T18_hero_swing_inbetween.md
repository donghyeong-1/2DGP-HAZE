# T18 주인공 휘두르기 사이 프레임 (T15 개선)

먼저 `docs/codex/COMMON.md`를 읽고 그 규칙을 따른다. T15와 같은 방식(저장된 원화·몸 레이어를 쓰고, 필요한 칸만 새로 생성 → `finish_character.py --like` → `check_sprites.py`)을 쓴다.

## 배경 (사용자 피드백 2026-11-17: "공격 애니메이션이 너무 부자연스럽다")
지금 휘두르기는 방향마다 3장(① 젖힘 ② 최대 신장 ③ 마무리)이다. 수평 방향을 보면 ①은 파이프가 머리 뒤로 높이 들려 있고 ②는 수평으로 곧게 뻗어 있어서, **그 사이(위 앞 45도로 내려오는 순간)가 없어 찌르기처럼 툭 튄다.** 게임 코드는 준비 프레임을 짧게 스치고 타격 프레임을 길게 보여 주는 식으로 메우고 있지만(`src/config.py` `SWING_STYLE_PHASES`) 궤적이 끊겨 보이는 것은 그림이 있어야 해결된다.

## 입력
- 지금 게임 적용본(T15): `assets/sprites/unified/n09_swing_<방향>_1~3.png`, 원본 `assets/sprites/forge/n09_swing_<방향>_v4/`, 작업 폴더 `forge/hero_pipe_v4/<방향>/`
- 정체성·화풍: `assets/sprites/forge/hero_v3b/master/master_rgba.png`, 팔레트 `n09_v3b`
- 파이프: T15와 같은 굵기(1배 5~6px), 길이 약 70px, 철 질감, 손잡이 쪽 청록 천 감김

## 요구사항
- 방향마다 **5프레임**으로 늘린다. 기존 3장은 ①·③·④ 자리에 그대로 쓰고(다시 만들지 않는다) **두 장만 새로** 만든다.
  | 번호 | 자세 | 출처 |
  |---|---|---|
  | ① | 젖힘(준비) | 기존 1번 |
  | ② | **휘두르는 중**: 파이프가 젖힘과 최대 신장의 중간 각도(수평 방향이면 위 앞 45도), 몸이 앞으로 기울기 시작, 앞발에 무게 | **새로** |
  | ③ | 최대 신장(타격) | 기존 2번 |
  | ④ | 마무리 | 기존 3번 |
  | ⑤ | **회수**: 파이프를 몸 쪽으로 당겨 대기 자세로 돌아가는 중간(파이프 끝이 아래 뒤쪽) | **새로** |
- **순서: 수평(side)부터.** 수평 5장이 합격 기준을 넘으면 앞 위(upfwd) → 앞 아래(downfwd) → 위(up) → 아래(down) 순으로 같은 방식. 시간이 모자라면 수평만 하고 멈춰도 된다(게임에서 가장 많이 쓰는 방향).
- 이름 `n09_swing_<방향>_v5` (프레임 5장), 새 폴더. 몸·얼굴·옷·발 바닥선은 T15와 같아야 한다(게임의 발 기준점을 그대로 쓰기 위해). 캔버스 크기가 달라지면 보고서에 프레임별 발 기준점(x, y)을 적는다.
- 휘두르는 궤적 선·잔상은 그리지 않는다(게임 이펙트가 따로 있다). 몸과 파이프만.
- 확인용 1배 strip과 GIF(①0.03 ②0.04 ③0.1 ④0.08 ⑤0.06초)를 보고서에 연결한다.

## 절차
방향마다: ① 새로 만들 2칸을 `$generate2dsprite`로 생성(기존 1·2번 원화를 참조 이미지로) → ② `process` → ③ `python tools/finish_character.py <frames_raw> n09_swing_<방향>_v5 --like n09_v3b` (T15처럼 몸 레이어를 그대로 얹는 방식이 낫다면 그렇게 하고 보고서에 적는다) → ④ 기존 3장과 합쳐 5장 폴더를 만들고 `check_sprites.py`.
보고서 `docs/codex/reports/T18.md`, 상태 `review`.
