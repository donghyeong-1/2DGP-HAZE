# T21 주인공 달리기 다시 그리기: 왼발·오른발 걸음이 번갈아 나오게 (T19 달리기 8장 고치기)

먼저 `docs/codex/COMMON.md`를 읽고 그 규칙을 따른다. T19와 같은 방식(격자 시트 → `process` → `finish_character.py --like` → `check_sprites.py`)을 쓴다. 영상 경로는 쓰지 않는다.
**전환 5장(`n09_run_trans_v1`)은 그대로 둔다.** 이 작업은 달리기 반복 8장만 다시 만든다.

## 문제 (사용자 플레이 2026-11-18: "발이 서로 교차를 안 해")
지금 달리기 8장(`assets/sprites/unified/n09_run_1~8.png`, 원본 `assets/sprites/forge/n09_run_v1/`)은 **5~8번이 1~4번과 거의 같은 그림**이다.
같은 다리·같은 팔이 8장 내내 앞에 나와서, 게임에서 보면 한쪽 발만 계속 내딛고 두 발이 서로 앞뒤로 엇갈리지 않는다.
- 숫자로: 반 주기 떨어진 장(1·5, 2·6, 3·7, 4·8)끼리 바뀐 픽셀이 평균 968개, 이웃한 장끼리는 2472개(비율 **0.39**). 제대로 번갈아 걷는 걷기 `n09_walk`는 **1.02**다.
- 눈으로: 청록 손목 띠를 찬 **가까운 쪽 팔이 8장 모두 앞**에 있다. 다리도 같은 쪽이 계속 앞이다.
- T19 합격 기준 "좌우 걸음이 구별된다"를 검토 때 놓쳤다(Claude Code 실수). 이번에는 아래 검사 도구로 숫자를 확인한다.

## 요구사항
### 달리기 8장 (`n09_run_v2`)
한 걸음 네 자세 × 두 걸음. **두 걸음은 앞에 나오는 다리와 팔이 반대다.**

| 장 | 자세 | 앞에 나온 다리 | 앞에 나온 팔 |
|---|---|---|---|
| ① | 접지 (앞발 뒤꿈치가 막 닿음) | **가까운 쪽** 다리 | **먼 쪽** 팔 |
| ② | 하강 (무릎 굽힘, 몸 가장 낮음) | 가까운 쪽 다리가 몸 밑 | 먼 쪽 팔 |
| ③ | 통과 (먼 쪽 다리가 몸 밑을 지나 앞으로) | 두 다리가 몸 밑에서 엇갈림 | 팔이 몸 옆을 지남 |
| ④ | 체공 (두 발 모두 뜸, 몸 가장 높음) | **먼 쪽** 다리가 앞으로 뻗음 | **가까운 쪽** 팔 |
| ⑤ | 접지 | **먼 쪽** 다리 | **가까운 쪽** 팔 |
| ⑥ | 하강 | 먼 쪽 다리가 몸 밑 | 가까운 쪽 팔 |
| ⑦ | 통과 (가까운 쪽 다리가 앞으로) | 두 다리가 몸 밑에서 엇갈림 | 팔이 몸 옆을 지남 |
| ⑧ | 체공 | **가까운 쪽** 다리가 앞으로 뻗음 | **먼 쪽** 팔 |

- **가까운 쪽**(화면 쪽) 팔다리는 밝게, **먼 쪽**은 두 단계 어둡게 그린다. 청록 손목 띠·무릎 찢어진 곳 같은 표시는 **그 팔다리를 따라** 움직인다(앞뒤가 바뀌면 표시도 같이 바뀐다).
- 팔은 다리와 반대로 흔든다: 가까운 쪽 다리가 앞이면 먼 쪽 팔이 앞.
- ⑤~⑧은 ①~④를 좌우 반전한 그림이면 안 된다(얼굴·옷이 뒤집힌다). 같은 오른쪽을 본 채 팔다리만 바뀐다.
- 나머지는 T19와 같다: 몸 앞으로 10~15° 기울임, 체공 장은 두 발이 바닥선에서 6px 이상, 몸 위아래 출렁임 4~6px, 벨트 버클 가로 위치 8장 ±2px, 접지 장의 두 발 사이 70~85px, 키·얼굴·옷·색은 지금 달리기·대기와 같다.
- **캔버스 105×129, 발 기준점 (55, 128)을 지금 `n09_run`과 같게** 맞추면 게임 코드를 고치지 않아도 된다. 다르면 보고서에 적는다.

### 만드는 요령 (T19에서 한 시트 8칸으로는 같은 걸음이 두 번 나왔다)
- 한 시트에 8칸을 한꺼번에 뽑지 말고, **걸음 A(①~④)와 걸음 B(⑤~⑧)를 따로** 만들어도 된다. 걸음 B를 만들 때 걸음 A 그림을 참고로 주고 "앞에 나온 다리와 팔을 반대로"를 분명히 적는다.
- 지금 `n09_run_1~4`가 걸음 A로 쓸 만하면 그대로 두고 ⑤~⑧만 새로 만들어도 된다(보고서에 적는다).
- 3번 시도해도 비율이 0.8에 못 미치면 멈추고 보고서에 시도한 것과 숫자를 적는다(억지로 합격시키지 않는다).
