# T24 철파이프 2단계 강화 동작 (올려베기 3장 + 내려찍기 3장)

먼저 `docs/codex/COMMON.md`를 읽고 그 규칙을 따른다. T18과 같은 방식(주인공 원화·몸 레이어 참조 → `$generate2dsprite` → `process` → `finish_character.py --like n09_v3b` → `check_sprites.py`)을 쓴다.

## 배경 (2026-11-20 사용자: "2번 강화 공격도 다른 공격 모션이면 좋겠다")
E를 두 번 쌓고 공격하면 **2단계 강화**가 나간다. 코드는 이미 만들었다(`src/weapon.py` `_stage2_rise` → 0.16초 뒤 `_stage2_slam`).
① **올려베기**: 땅에 붙인 파이프를 앞 아래에서 머리 위로 크게 쳐올린다(맞은 적이 살짝 뜬다).
② **내려찍기**: 뛰어오르듯 몸을 띄웠다가 파이프를 두 손으로 잡고 앞 바닥에 내리꽂는다(바닥 충격 이펙트는 코드가 그린다).
지금은 휘두르기 그림(위·앞아래)을 빌려 써서 1단계 강화(크게 한 번 휘두르기)와 구별이 약하다. **이 두 동작이 한눈에 다르게 보이는 것이 핵심이다.**

## 입력
- 정체성·화풍: `assets/sprites/forge/hero_v3b/master/master_rgba.png`, 팔레트 `n09_v3b`
- 파이프: T15·T18과 같은 굵기(1배 5~6px), 길이 약 70px, 손잡이 쪽 청록 천
- 비교: 게임 적용본 `assets/sprites/unified/n09_swing_side_1~4.png`, `n09_plunge_1~2.png`, `n09_ult_1~2.png`

## 동작 (6장)
| 이름 | 장 | 자세 |
|---|---|---|
| `n09_s2rise` | 3 | ① 낮게 웅크려 파이프 끝을 앞 바닥 근처에 둠 ② 쳐올리는 중(파이프가 앞 수평, 몸이 펴짐) ③ 파이프가 머리 위 뒤쪽까지, 뒤꿈치가 들림 |
| `n09_s2slam` | 3 | ① 두 손으로 파이프를 머리 위로 든 채 몸이 떠오름(무릎 굽힘) ② 내리치는 중(파이프 앞 45도 아래) ③ 파이프 끝이 앞 바닥에 닿고 몸이 낮게 숙여짐, 앞발 크게 내딛음 |

- 오른쪽을 본다. 발 바닥선은 대기·휘두르기와 같게(공중인 s2slam ①은 바닥선보다 발이 위에). 프레임별 발 기준점(x, y)을 보고서에 적는다.
- 궤적·잔상·충격파는 그리지 않는다(코드 이펙트).
- 새 폴더 `assets/sprites/forge/n09_stage2_v1/frames/`에 `s2rise-1~3.png`, `s2slam-1~3.png`, 1배 strip, GIF(0.05·0.05·0.08 / 0.06·0.04·0.12초).
