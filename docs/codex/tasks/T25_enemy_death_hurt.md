# T25 일반 적 4종 사망 동작 3장 + 피격 2장째

먼저 `docs/codex/COMMON.md`를 읽고 그 규칙을 따른다. T09·T12와 같은 방식(격자 시트 → `process` → `finish_character.py --like <적 마감 기준>` → `check_sprites.py`)을 쓴다.

## 배경 (퀄리티 상승 계획 1-2, `docs/quality_plan.md`)
지금 일반 적(슬럼 폐인·고철 투척병·안개 사냥개·중장갑 간수)은 죽으면 **연기만 나고 그림이 사라진다.** 피격도 한 장이라 맞을 때 움찔하는 느낌이 약하다. 스팀 수준의 손맛에는 "쓰러지는 그림"이 꼭 필요하다.

## 입력 (마감 기준 = 게임 정지 그림과 같은 파일)
- 슬럼 `remake_t01_t03/finished/enemy_slum_remake/`(키 117), 투척병 `.../enemy_thrower_remake/`(123), 간수 `.../enemy_guard_remake/`(135), 사냥개 `.../enemy_hound_fit_remake/`(81). 원화는 같은 이름의 `master/`.
- 지금 피격 그림 `assets/sprites/unified/enemy_<종류>_hurt_1.png`(이것을 ①로 그대로 둔다)

## 동작 (적마다 4장, 모두 16장)
| 이름 | 장 | 자세 |
|---|---|---|
| `enemy_<종류>_hurt` | 1장 새로 (②) | 뒤로 더 크게 젖혀 비틀거림(①보다 머리가 뒤로, 한 발이 들림) |
| `enemy_<종류>_death` | 3 | ① 맞고 뒤로 휘청(무릎 꺾임) ② 무릎 꿇거나 옆으로 기울며 쓰러지는 중 ③ 바닥에 엎드린·누운 자세(높이가 키의 1/3 이하) |

- 왼쪽을 보는 적은 기존 그림과 같은 방향으로. 사냥개는 옆으로 쓰러지는 개 자세.
- 바닥선은 기존 그림과 같게. ③은 가로로 길어지므로 캔버스가 넓어지면 기준점을 보고서에.
- 피·잘린 신체 금지(청록 안개가 빠져나가는 정도는 코드 이펙트가 그린다).
- 새 폴더 `assets/sprites/forge/enemy_death_v1/<종류>/frames/`.

## 절차
슬럼 → 투척병 → 간수 → 사냥개 순서(자주 나오는 순). 같은 이미지는 최대 3번. 보고서 `docs/codex/reports/T25.md`, 상태 `review`.

- [ ] 4종 모두 1배에서 "쓰러진다"로 읽힌다, 정지 그림과 같은 인물·색
- [ ] 피격 ①·②를 번갈아 보면 움찔거림이 보인다
- [ ] 보고서에 솔직하게 (못 한 종류 포함)
