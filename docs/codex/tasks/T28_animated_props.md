# T28 스테이지별 움직이는 배경 소품 (반복 4장씩)

먼저 `docs/codex/COMMON.md`를 읽고 그 규칙을 따른다. 캐릭터가 아니라 소품이므로 `$generate2dsprite`(prop 시트) 또는 `$generate2dmap`(prop pack)을 쓰고, 마감은 T14(진열대)와 같은 방식(32색 이하, 확대 금지, 1배 그대로)으로 한다.

## 배경 (퀄리티 상승 계획 2-1)
지금 방은 타일·원경·중경이 모두 멈춰 있어 화면이 정지 화면처럼 보인다. 스팀 수준의 2D 액션은 배경에서 무언가 늘 움직인다(증기, 흔들리는 등, 깜빡이는 빛). 소품은 충돌 없이 그림만 놓는다(배치·반복 재생은 Claude Code).

## 입력
- 테마와 색: 원경 `assets/backgrounds/far_<테마>.png`, 타일 `assets/tiles/tile_set_<테마>.png`. 테마 이름: 스테이지 1 `cell`, 스테이지 2 `foundry`, 스테이지 3 `haze`, 은신처 `hideout`(원경 `far_hideout.png`, 타일은 foundry)
- 크기 기준: 타일 60px, 주인공 키 123px

## 소품 (테마마다 3종, 모두 12종 × 4장)
| 테마 | 소품 (각 4장 반복) |
|---|---|
| 슬럼 `cell`(stage1) | 천장에서 떨어지는 물방울과 웅덩이 파문 / 바람에 흔들리는 누더기 천 / 깜빡이는 낡은 전구 |
| 공장 `foundry`(stage2) | 배관에서 뿜는 증기 / 돌아가는 톱니바퀴 / 위아래로 움직이는 피스톤 |
| 탑 `haze`(stage3) | 청록으로 맥동하는 헤이즈 결정 기둥 / 좌우로 훑는 감시등 / 흔들리는 사슬 |
| 은신처 `hideout` | 화로 불꽃 / 모루 위 불똥 / 천장 환풍기 |

- 소품 하나는 60~180px 안. 배경 앞에 놓이므로 원경보다 진하고 타일보다 약간 어둡게(플레이어·적보다 눈에 띄면 안 된다).
- 4장을 이어 재생하면 끊김 없이 돈다(마지막 → 처음).
- 새 폴더 `assets/sprites/forge/props_anim_v1/<테마>/<소품>/frames/1~4.png`, 1배 strip, GIF(각 0.12초).

## 절차
슬럼 → 공장 → 탑 → 은신처. 같은 이미지는 최대 3번. 보고서 `docs/codex/reports/T28.md`, 상태 `review`.
