# T29 상점 페이지 그림 (스팀 규격 캡슐 + 로고)

먼저 `docs/codex/COMMON.md`를 읽고 그 규칙을 따른다. 화면 일러스트(T11·T16)와 같은 방식(`$generate2dmap`/image_gen 원화 → 프로젝트 hibit 마감, 확대 금지)을 쓴다.

## 배경 (퀄리티 상승 계획 3-3)
교수님 기준이 "스팀에 출시할 수 있는 수준"이라, 상점 페이지에 쓰는 그림까지 갖춘다(발표 자료 표지에도 쓴다). 실제로 스팀에 올리지는 않는다.

## 입력
- 제목 화면 `assets/backgrounds/screen_title.png`(T16), 컷인 `assets/ui/ult_cutin.png`(T23), 주인공 마스터 `forge/hero_v3b/master/master_rgba.png`
- 게임 제목: 《헤이즈 (HAZE)》, 부제 "안개를 삼키고 탈출하라"

## 그림 (스팀 규격 크기 그대로, 픽셀 화풍)
| 이름 | 크기 | 내용 |
|---|---|---|
| `capsule_header` | 920×430 | 주인공이 철파이프를 들고 헤이즈 안개 속 감옥 복도에 선 모습 + 제목 자리 |

- 새 폴더 `assets/sprites/forge/store_art_v1/`.

logo → capsule_header → capsule_main → 나머지. 같은 이미지는 최대 3번. 보고서 `docs/codex/reports/T29.md`, 상태 `review`.
