# T31 테마별 방 장식 소품 (멈춘 그림, 테마마다 6종)

먼저 `docs/codex/COMMON.md`를 읽고 그 규칙을 따른다. 소품이므로 `$generate2dsprite`(prop 시트) 또는 `$generate2dmap`(prop pack)을 쓰고, 마감은 T14·T28과 같은 방식(32색 이하, 확대 금지, 1배 그대로, 알파는 0 또는 255)으로 한다.

## 배경 (퀄리티 계획 2-4 "방 구성 늘리기")
Claude Code가 스테이지마다 방 모양을 늘린다. 지금 방은 타일과 원경만 있어 **방마다 볼거리가 비슷하다.** 움직이는 소품(T28) 사이사이에 놓을 **멈춘 장식**이 있으면 같은 타일로도 방이 달라 보인다. 충돌은 없고 그림만 놓는다(배치는 Claude Code).

## 입력
- 테마와 색: 원경 `assets/backgrounds/far_<테마>.png`, 중경 `mid_<테마>.png`, 타일 `assets/tiles/tile_set_<테마>.png`, T28 결과 `assets/sprites/forge/props_anim_v1/<테마>/`
- 크기 기준: 타일 60px, 주인공 키 123px

## 소품 (18종)
| 테마 | 바닥에 놓는 것 (3) | 벽·천장에 거는 것 (3) |
|---|---|---|
| 슬럼 `cell`(stage1) | 부서진 나무 상자 더미 / 녹슨 드럼통 / 쓰레기·누더기 더미 | 철창 창문 / 벗겨진 수배 전단(글자 없이 얼굴 실루엣만) / 늘어진 전선 |
| 공장 `foundry`(stage2) | 쇳덩이 수레 / 쌓인 거푸집 / 공구함 | 경고 표지판(그림 기호만, 글자 없음) / 벽 계기판 / 매달린 갈고리 |
| 탑 `haze`(stage3) | 깨진 헤이즈 결정 조각 / 쓰러진 감시 로봇 잔해 / 봉인된 상자 | 청록 문양 벽 패널 / 깨진 모니터 / 감시 카메라 |

- 바닥 소품 높이 40~150px, 벽 소품 40~160px. 원경보다 진하고 타일보다 약간 어둡게(캐릭터보다 눈에 띄면 안 된다). 빛은 왼쪽 위.
- **글자 넣지 않는다**(한글·영어 모두. 축소하면 깨진다).
- 바닥 소품은 바닥선이 그림 맨 아래 줄에 닿게.
- 새 폴더 `assets/sprites/forge/room_decor_v1/<테마>/<소품>.png` + 테마별 1배 비교 시트 `assets/sprites/forge/room_decor_v1/<테마>_sheet_1x.png`.

## 절차
슬럼 → 공장 → 탑. 테마마다 시트 한 장으로 6종을 만들고 잘라도 된다. 같은 이미지는 최대 3번. 보고서 `docs/codex/reports/T31.md`, 상태 `review`.

## 합격 기준
- [ ] 1배로 타일·원경 위에 놓았을 때 테마에 어울린다(보고서에 합성 미리보기 1장)
- [ ] 글자 없음, 알파는 0·255만
- [ ] 보고서에 솔직하게 (못 만든 소품 포함)
