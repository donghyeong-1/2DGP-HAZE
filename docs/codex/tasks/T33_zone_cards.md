# T33 구역 제목 카드 일러스트 (슬럼·공장·탑, 3장)

먼저 `docs/codex/COMMON.md`를 읽고 그 규칙을 따른다. 배경·장면이므로 `$generate2dmap`(plate)을 쓰고, 마감은 T16(제목 화면)과 같은 방식으로 한다.

## 배경
지금은 구역(스테이지)에 들어가도 바로 첫 방이 나온다. 구역이 바뀌는 순간에 **가로 띠 일러스트 + 구역 이름**이 잠깐 지나가면 "새 장에 들어왔다"는 느낌이 산다. 트레일러·발표 자료에도 쓴다. 글자(구역 이름)는 Claude Code가 게임에서 그 위에 쓴다.

## 입력
- 원경 `assets/backgrounds/far_cell.png`(슬럼), `far_foundry.png`(공장), `far_haze.png`(탑), 제목 화면 `assets/backgrounds/screen_title.png`(화풍 기준)
- 인물을 넣는다면 주인공 실루엣만(작게, 뒷모습 또는 옆모습). 적·보스는 넣지 않는다.

## 그림 (3장)
| 이름 | 장면 |
|---|---|
| `zone_cell` | 비 내리는 슬럼 골목 끝, 멀리 감옥 탑. 젖은 바닥에 청록 헤이즈가 고여 있다 |
| `zone_foundry` | 용광로 불빛이 새는 거대한 공장 내부, 컨베이어와 증기 |
| `zone_haze` | 청록 헤이즈 결정이 자라난 탑 꼭대기로 이어지는 계단, 위가 밝다 |

- 크기 **1920x400**(1배, 화면 가로 그대로), 가운데 세로 1/3은 비교적 어둡고 단순하게(그 위에 큰 글자가 올라간다). 글자 넣지 않는다.
- 색은 각 원경과 같은 계열, 32색 이하 픽셀 마감.
- 새 폴더 `assets/sprites/forge/zone_cards_v1/<이름>.png` + 세 장을 세로로 붙인 비교 시트.

## 절차
슬럼 → 공장 → 탑. 같은 이미지는 최대 3번. 보고서 `docs/codex/reports/T33.md`, 상태 `review`.

## 합격 기준
- [ ] 세 장이 한눈에 다른 장소이고, 각 원경과 같은 세계로 보인다
- [ ] 가운데에 글자를 올려도 읽힐 만큼 차분하다(보고서에 가짜 글자를 얹은 미리보기 1장)
- [ ] 보고서에 솔직하게
