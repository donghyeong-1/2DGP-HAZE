# T36 용접 드론 (공장, 날아다니는 적)

먼저 `docs/codex/COMMON.md`를 읽고 그 규칙을 따른다. 새 캐릭터이므로 **마스터 스틸 1장 → 동작 격자 시트 → `process` → `finish_character.py <원화> enemy_drone --height 90` → `check_sprites.py`** 순서다(T10·T27과 같은 방식, 키는 `--height`로 준다).

## 배경 (v5 계획 1, `docs/plan_v5.md`)
사용자: "항상 똑같은 적만 본다." 구역마다 그 구역에만 나오는 새 적을 더한다. 이 적은 **스테이지 2 공장**에 나온다.
날아다니며 플레이어 위에서 짧은 직선 불꽃을 쏜다. 마우스로 위를 조준하게 만드는 첫 비행 적이다.

## 입력 (화풍·색 기준)
- 같은 구역 적: `assets/sprites/unified/enemy_guard_idle.png`, `enemy_thrower_idle.png`, 크래셔 `boss_crasher_idle_1.png`
- 구역 원경 `assets/backgrounds/far_foundry.png`, 타일 `assets/tiles/tile_set_foundry.png`
- 키 기준: 주인공 123px. 이 적의 키 **90px** (몸통 폭 약 110px, 날개·프로펠러 포함)

## 생김새
녹슨 주황 철판 몸통의 작은 공장 드론. 위에 프로펠러 둘, 아래에 용접 토치 팔 하나, 가운데 청록 헤이즈 렌즈 눈. 굵은 실루엣.

## 동작 (13장)
| 이름 | 장 | 자세 |
|---|---|---|
| `fly` | 4 | 제자리 비행(프로펠러 회전, 몸이 1~2px 오르내림) |
| `aim` | 2 | 공격 예고: 토치가 아래로 향하고 렌즈가 밝아짐 |
| `fire` | 3 | 불꽃 분사(토치 끝 불꽃은 그리지 말고 노즐만 밝게 — 불꽃은 게임이 코드로 그린다) |
| `hurt` | 2 | 맞아 기울어짐 |
| `death` | 2 | 불꽃 튀며 기울어 떨어짐 -> 부서진 잔해 |

- 오른쪽을 보는 그림. 같은 동작 안에서 몸통 위치는 거의 같게(게임이 옮긴다). 기준점(발 가운데 또는 몸 중심 x, 바닥 y)을 보고서에.
- 새 폴더 `assets/sprites/forge/drone_v1/` (마스터 `master/`, 동작별 `frames/<동작>-<번호>.png`, 1배 비교판, GIF).

## 절차
마스터 → 비행 → 예고·분사 → 피격 → 쓰러짐. 같은 이미지는 최대 3번. 보고서 `docs/codex/reports/T36.md`, 상태 `review`.
