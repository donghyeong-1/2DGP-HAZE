# T37 자폭 수레 (공장, 달려와 터지는 적)

먼저 `docs/codex/COMMON.md`를 읽고 그 규칙을 따른다. 새 캐릭터이므로 **마스터 스틸 1장 → 동작 격자 시트 → `process` → `finish_character.py <원화> enemy_cart --height 75` → `check_sprites.py`** 순서다(T10·T27과 같은 방식, 키는 `--height`로 준다).

## 배경 (v5 계획 1, `docs/plan_v5.md`)
사용자: "항상 똑같은 적만 본다." 구역마다 그 구역에만 나오는 새 적을 더한다. 이 적은 **스테이지 2 공장**에 나온다.
플레이어에게 굴러와 터진다. 맞히면 튕겨 나가 적 쪽으로 되돌려 보낼 수 있다(받아치기).

## 입력 (화풍·색 기준)
- 같은 구역 적: `assets/sprites/unified/enemy_guard_idle.png`, 크래셔, 공장 장식 `assets/decor/foundry_scrap_cart.png`
- 구역 원경 `assets/backgrounds/far_foundry.png`, 타일 `assets/tiles/tile_set_foundry.png`
- 키 기준: 주인공 123px. 이 적의 키 **75px** (폭 약 110px)

## 생김새
고철을 실은 작은 광산 수레에 빨간 경고등과 헤이즈 통이 묶여 있다. 앞에 찌그러진 범퍼, 바퀴 넷.

## 동작 (11장)
| 이름 | 장 | 자세 |
|---|---|---|
| `roll` | 4 | 굴러감(바퀴 회전, 고철이 덜컹) |
| `arm` | 3 | 폭발 직전: 경고등이 빨갛게 깜빡, 통이 부풂(1->3 점점) |
| `hurt` | 2 | 맞아 뒤로 튕김(앞바퀴가 들림) |
| `wreck` | 2 | 터진 뒤 남은 그을린 잔해 |

- 오른쪽을 보는 그림. 같은 동작 안에서 몸통 위치는 거의 같게(게임이 옮긴다). 기준점(발 가운데 또는 몸 중심 x, 바닥 y)을 보고서에.
- 새 폴더 `assets/sprites/forge/cart_v1/` (마스터 `master/`, 동작별 `frames/<동작>-<번호>.png`, 1배 비교판, GIF).

## 절차
마스터 → 굴러감 → 폭발 직전 → 피격 → 잔해. 같은 이미지는 최대 3번. 보고서 `docs/codex/reports/T37.md`, 상태 `review`.
