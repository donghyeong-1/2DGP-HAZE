# T39 결정 기사 (탑, 순간이동해 베는 적)

먼저 `docs/codex/COMMON.md`를 읽고 그 규칙을 따른다. 새 캐릭터이므로 **마스터 스틸 1장 → 동작 격자 시트 → `process` → `finish_character.py <원화> enemy_knight --height 132` → `check_sprites.py`** 순서다(T10·T27과 같은 방식, 키는 `--height`로 준다).

## 배경 (v5 계획 1, `docs/plan_v5.md`)
사용자: "항상 똑같은 적만 본다." 구역마다 그 구역에만 나오는 새 적을 더한다. 이 적은 **스테이지 3 탑**에 나온다.
헤이즈로 사라졌다가 플레이어 옆에 나타나 결정 칼로 벤다. 맞으면 결정 파편이 흩어진다.

## 입력 (화풍·색 기준)
- 같은 구역 적: `assets/sprites/unified/enemy_guard_idle.png`(간수 크기·갑옷 기준), 아크 `boss_ark_idle_1.png`
- 구역 원경 `assets/backgrounds/far_haze.png`, 타일 `assets/tiles/tile_set_haze.png`
- 키 기준: 주인공 123px. 이 적의 키 **132px**

## 생김새
청록 헤이즈 결정이 갑옷 틈마다 자라난 감옥 기사. 한 손에 결정 장검, 얼굴은 투구로 가려짐. 간수보다 날렵하다.

## 동작 (14장)
| 이름 | 장 | 자세 |
|---|---|---|
| `idle` | 2 | 칼을 낮게 든 대기 |
| `walk` | 4 | 걷기(발 교대) |
| `vanish` | 2 | 헤이즈로 흩어지며 사라짐 |
| `appear` | 2 | 나타남(결정이 모여 몸이 됨) |
| `slash` | 3 | 예고(칼을 뒤로) -> 베기 -> 회수 |
| `hurt` | 1 | 맞아 젖힘 |

- 오른쪽을 보는 그림. 같은 동작 안에서 몸통 위치는 거의 같게(게임이 옮긴다). 기준점(발 가운데 또는 몸 중심 x, 바닥 y)을 보고서에.
- 새 폴더 `assets/sprites/forge/knight_v1/` (마스터 `master/`, 동작별 `frames/<동작>-<번호>.png`, 1배 비교판, GIF).

## 절차
마스터 → 대기·걷기 → 사라짐·나타남 → 베기 → 피격 (쓰러짐은 기존처럼 헤이즈로 흩어짐, 그리지 않는다). 같은 이미지는 최대 3번. 보고서 `docs/codex/reports/T39.md`, 상태 `review`.
