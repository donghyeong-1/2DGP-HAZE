# T40 헤이즈 망령 (탑, 벽을 통과하는 적)

먼저 `docs/codex/COMMON.md`를 읽고 그 규칙을 따른다. 새 캐릭터이므로 **마스터 스틸 1장 → 동작 격자 시트 → `process` → `finish_character.py <원화> enemy_wraith --height 110` → `check_sprites.py`** 순서다(T10·T27과 같은 방식, 키는 `--height`로 준다).

## 배경 (v5 계획 1, `docs/plan_v5.md`)
사용자: "항상 똑같은 적만 본다." 구역마다 그 구역에만 나오는 새 적을 더한다. 이 적은 **스테이지 3 탑**에 나온다.
벽을 통과해 천천히 다가와 닿으면 게이지를 빼앗는다. 공격 맞으면 잠깐 흐트러진다.

## 입력 (화풍·색 기준)
- 같은 구역 적: 헤이즈 이펙트 `assets/effects/aura-awake.png`, 아크
- 구역 원경 `assets/backgrounds/far_haze.png`, 타일 `assets/tiles/tile_set_haze.png`
- 키 기준: 주인공 123px. 이 적의 키 **110px** (아래는 연기 꼬리, 발 없음)

## 생김새
청록 헤이즈가 사람 상반신 모양으로 뭉친 망령. 텅 빈 눈 두 개가 밝게 빛남, 아래는 흩어지는 연기 꼬리. **반투명 금지**: 색면과 점묘로 흐릿함을 표현.

## 동작 (10장)
| 이름 | 장 | 자세 |
|---|---|---|
| `float` | 4 | 떠다님(꼬리가 흔들림) |
| `grab` | 3 | 팔을 뻗어 빨아들임 |
| `hurt` | 1 | 흐트러짐 |
| `death` | 2 | 흩어져 사라짐 |

- 오른쪽을 보는 그림. 같은 동작 안에서 몸통 위치는 거의 같게(게임이 옮긴다). 기준점(발 가운데 또는 몸 중심 x, 바닥 y)을 보고서에.
- 새 폴더 `assets/sprites/forge/wraith_v1/` (마스터 `master/`, 동작별 `frames/<동작>-<번호>.png`, 1배 비교판, GIF).

## 절차
마스터 → 떠다님 → 빨아들임 → 흐트러짐 → 사라짐. 같은 이미지는 최대 3번. 보고서 `docs/codex/reports/T40.md`, 상태 `review`.
