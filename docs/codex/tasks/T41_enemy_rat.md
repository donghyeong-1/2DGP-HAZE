# T41 헤이즈 쥐 떼 (슬럼, 작고 빠른 무리)

먼저 `docs/codex/COMMON.md`를 읽고 그 규칙을 따른다. 새 캐릭터이므로 **마스터 스틸 1장 → 동작 격자 시트 → `process` → `finish_character.py <원화> enemy_rat --height 40` → `check_sprites.py`** 순서다(T10·T27과 같은 방식, 키는 `--height`로 준다).

## 배경 (v5 계획 1, `docs/plan_v5.md`)
사용자: "항상 똑같은 적만 본다." 구역마다 그 구역에만 나오는 새 적을 더한다. 이 적은 **스테이지 1 슬럼**에 나온다.
작고 빨라 무리로 몰려온다. 한 대에 죽는다. 광역 공격이 빛나게 한다.

## 입력 (화풍·색 기준)
- 같은 구역 적: `assets/sprites/unified/enemy_hound_idle.png`(사냥개, 같은 슬럼 동물), 슬럼
- 구역 원경 `assets/backgrounds/far_cell.png`, 타일 `assets/tiles/tile_set_cell.png`
- 키 기준: 주인공 123px. 이 적의 키 **40px** (몸길이 약 60px)

## 생김새
헤이즈에 오염된 큰 시궁쥐. 등에 청록 결정 돌기, 빨간 눈, 긴 꼬리. 사냥개와 같은 털 색 계열.

## 동작 (9장)
| 이름 | 장 | 자세 |
|---|---|---|
| `run` | 4 | 달리기(발 교대) |
| `bite` | 2 | 뛰어올라 묾 |
| `hurt` | 1 | 움찔 |
| `death` | 2 | 뒤집혀 쓰러짐 |

- 오른쪽을 보는 그림. 같은 동작 안에서 몸통 위치는 거의 같게(게임이 옮긴다). 기준점(발 가운데 또는 몸 중심 x, 바닥 y)을 보고서에.
- 새 폴더 `assets/sprites/forge/rat_v1/` (마스터 `master/`, 동작별 `frames/<동작>-<번호>.png`, 1배 비교판, GIF).

## 절차
마스터 → 달리기 → 물기 → 피격 → 쓰러짐. 같은 이미지는 최대 3번. 보고서 `docs/codex/reports/T41.md`, 상태 `review`.
