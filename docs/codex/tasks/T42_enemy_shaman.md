# T42 누더기 무당 (슬럼, 보호막을 거는 적)

먼저 `docs/codex/COMMON.md`를 읽고 그 규칙을 따른다. 새 캐릭터이므로 **마스터 스틸 1장 → 동작 격자 시트 → `process` → `finish_character.py <원화> enemy_shaman --height 120` → `check_sprites.py`** 순서다(T10·T27과 같은 방식, 키는 `--height`로 준다).

## 배경 (v5 계획 1, `docs/plan_v5.md`)
사용자: "항상 똑같은 적만 본다." 구역마다 그 구역에만 나오는 새 적을 더한다. 이 적은 **스테이지 1 슬럼**에 나온다.
뒤쪽에서 지팡이로 다른 적에게 보호막을 건다. 먼저 잡아야 할 대상.

## 입력 (화풍·색 기준)
- 같은 구역 적: `assets/sprites/unified/enemy_slum_idle.png`, `enemy_thrower_idle.png`, 보관인 NPC(후드 재질 참고)
- 구역 원경 `assets/backgrounds/far_cell.png`, 타일 `assets/tiles/tile_set_cell.png`
- 키 기준: 주인공 123px. 이 적의 키 **120px**

## 생김새
누더기 후드를 쓴 마른 슬럼 주민. 고철과 헤이즈 결정을 엮은 지팡이, 목에 부적 줄. 슬럼 폐인보다 조금 크고 꼿꼿함.

## 동작 (11장)
| 이름 | 장 | 자세 |
|---|---|---|
| `idle` | 2 | 지팡이 짚고 흔들림 |
| `walk` | 4 | 뒤로 물러서기 겸 걷기 |
| `cast` | 3 | 지팡이를 들어 보호막(지팡이 끝 결정이 밝아짐) |
| `hurt` | 2 | 맞아 휘청 |

- 오른쪽을 보는 그림. 같은 동작 안에서 몸통 위치는 거의 같게(게임이 옮긴다). 기준점(발 가운데 또는 몸 중심 x, 바닥 y)을 보고서에.
- 새 폴더 `assets/sprites/forge/shaman_v1/` (마스터 `master/`, 동작별 `frames/<동작>-<번호>.png`, 1배 비교판, GIF).

## 절차
마스터 → 대기·걷기 → 시전 → 피격. 같은 이미지는 최대 3번. 보고서 `docs/codex/reports/T42.md`, 상태 `review`.
