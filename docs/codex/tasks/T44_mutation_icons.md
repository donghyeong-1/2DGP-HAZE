# T44 헤이즈 변이·방 보상 아이콘

먼저 `docs/codex/COMMON.md`를 읽고 그 규칙을 따른다. 아이콘은 T06(아이템 아이콘)과 같은 방식(아이콘 시트 → 마감, 1배, 알파 0·255, 32색 이하).

## 배경 (v5 계획 3)
방을 깨면 '헤이즈 변이' 셋 중 하나를 고르는 카드 창이 나오고(하데스 축복처럼), 문 위에는 그 방을 깨면 받을 보상 아이콘이 뜬다(코드는 Claude Code).

## 그림
1. **변이 계열 문양 4종** (64x64): `bloom`(각성 — 피어나는 청록 꽃 결정), `ember`(위험 — 붉은 불씨), `hollow`(페이드 — 텅 빈 남색 고리), `tide`(강화 — 보라·금 소용돌이). 카드 위쪽에 크게 들어간다.
2. **카드 테두리 3종** (300x420): 일반(쇠), 희귀(청록 결정 장식), 전설(금 + 진홍 결정). 가운데는 비워 둔다(글자가 들어간다). 9칸 자르기가 되게 모서리 장식은 모서리 120px 안에.
3. **방 보상 아이콘 6종** (48x48): 조각, 회복(심장), 변이(결정 꽃), 헤이즈 결정(영구 재화), 무기 강화(망치), 위험(해골). 문 위 작은 판에 들어간다.

- 기존 아이콘 `assets/ui/icon_*.png`과 같은 선 굵기·색감. 글자 넣지 않는다.
- 새 폴더 `assets/sprites/forge/mutation_ui_v1/` + 1배 비교판.

## 절차
문양 → 카드 테두리 → 보상 아이콘. 같은 이미지 최대 3번. 보고서 `docs/codex/reports/T44.md`, 상태 `review`.
