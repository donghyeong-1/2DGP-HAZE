# T45 거대 보스 '헤이즈 심장' 본체

먼저 `docs/codex/COMMON.md`를 읽고 그 규칙을 따른다. 화면을 채우는 큰 그림이므로 T16·T33처럼 `$generate2dmap`/image_gen 원화 → hibit 마감(1배, 32~48색, 큰 판은 블록을 키워 픽셀 화풍 유지)을 쓴다. 알파는 0·255.

## 배경 (v5 계획 2-2)
최종 결전. 아크를 쓰러뜨리면 탑 꼭대기 방 뒤편 벽이 열리며 아크의 진짜 모습인 거대 보스가 등장한다. 화면 위쪽 절반을 차지하는 **본체** + 따로 움직이는 **기계 손 둘**(T46). 본체는 움직이지 않고 열리고 닫힌다.

## 입력
- 아크 `assets/sprites/unified/boss_ark_*`, 아크 마스터 `assets/sprites/forge/remake_t01_t03/boss_ark/master/master_rgba.png`(제복의 가슴 결정·모자 문양을 본체 디자인에 이어 받는다)
- 탑 원경 `far_haze.png`, 보스방 `far_boss.png`, 보스 카드 `assets/backgrounds/boss_card_ark.png`

## 그림
| 이름 | 크기 | 장 | 내용 |
|---|---|---|---|
| `heart_core` | 약 900x560 (투명 배경) | 3 | 탑 기계와 하나가 된 거대한 헤이즈 결정 심장. 가운데 **약점(빛나는 핵)** 을 감싼 금속 껍질. ① 닫힘 ② 반쯤 열림 ③ 활짝 열려 핵이 드러남 |
| `heart_core_hurt` | 같은 크기 | 1 | 맞아 금 간 핵(③을 바탕으로) |
| `heart_core_dying` | 같은 크기 | 2 | 무너짐: 금이 퍼짐 -> 껍질이 떨어져 나감 |

- 세 장의 외곽(껍질 테두리)이 같은 자리여야 한다(여닫는 것만 바뀜). 보고서에 핵 가운데 좌표.
- 새 폴더 `assets/sprites/forge/heart_core_v1/`.

## 절차
닫힘 원화 → 열림 단계 → 피격 → 무너짐. 같은 이미지 최대 3번. 보고서 `docs/codex/reports/T45.md`, 상태 `review`.
