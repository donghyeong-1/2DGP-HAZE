# T46 '헤이즈 심장'의 기계 손 (둘, 따로 움직임)

먼저 `docs/codex/COMMON.md`를 읽고 그 규칙을 따른다. T45와 같은 마감(1배, 알파 0·255, 32~48색).

## 배경 (v5 계획 2-2)
헤이즈 심장의 두 손. 화면을 날아다니며 내려치고, 손바닥으로 레이저를 훑는다. 손 하나하나에 체력이 있고 기절시키면 본체가 열린다. 오른손만 그리면 게임이 뒤집어 왼손으로 쓴다.

## 입력
- T45 결과 `assets/sprites/forge/heart_core_v1/`(같은 금속·결정), 아크 장갑(손 모양 참고)

## 그림 (오른손, 각 약 260x260)
| 이름 | 장 | 자세 |
|---|---|---|
| `hand_idle` | 2 | 손가락을 편 채 떠 있음(손목 관절이 살짝 움직임) |
| `hand_fist` | 2 | 주먹 쥐고 들어 올림(내려치기 예고) -> 내려치는 주먹 |
| `hand_palm` | 2 | 손바닥을 아래로 펴고 가운데 결정이 밝아짐(레이저 예고 -> 발사) |
| `hand_stun` | 2 | 기절: 손가락이 늘어지고 결정 빛이 꺼짐 |

- 손목 끝(본체와 이어지는 쪽)은 케이블 묶음으로 끝난다. 기준점(손 중심)을 보고서에.
- 새 폴더 `assets/sprites/forge/heart_hands_v1/`.

## 절차
대기 → 주먹 → 손바닥 → 기절. 같은 이미지 최대 3번. 보고서 `docs/codex/reports/T46.md`, 상태 `review`.
