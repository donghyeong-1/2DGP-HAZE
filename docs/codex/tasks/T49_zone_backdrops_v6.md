# T49 v6 구역 배경 다시 그리기 (원경·중경, 슬럼·공장·탑)

먼저 `docs/codex/COMMON.md`를 읽고 그 규칙을 따른다. 배경은 `$generate2dmap` 스킬로 만든다.

## 배경 (v6 `docs/plan_v6.md`)
화풍을 바꾼다. 픽셀 크기를 하나로 맞추려고 게임 세계를 **내부 해상도 960×540을 2배로** 그린다(주인공 약 62px).
배경도 이 규격에 맞춰 **960×540(또는 가로로 긴 중경은 그 배수 폭) 크기로 그리고, 게임이 2배로 키운다.**
참고: INARI(1HP STUDIO)의 연출 기법만 가져온다 — 장면마다 **지배색 하나 + 강조색 한두 개**, 디테일보다 명암 단계로 깊이,
방 밖은 거의 검게 비우고 작은 등불이 따뜻한 빛 웅덩이를 만든다, 위쪽을 덩굴·배관 같은 장식 층이 채운다.
INARI의 소재(동양 사원·성벽·붉은 정원)는 쓰지 않는다. 헤이즈 세계관(`docs/기획서.md`) 그대로.

## 그림 (구역마다 원경 1 + 중경 1, 모두 6장)
| 이름 | 크기 | 지배색 / 강조색 | 내용 |
|---|---|---|---|
| `far_cell` | 960×540 | 짙은 남색·푸른 회색 / 젖은 청록 반사, 노란 창문 몇 개 | 슬럼: 비 내리는 판자촌 실루엣이 겹겹이 멀어짐, 멀리 감시탑 |
| `mid_cell` | 1440×540, 좌우 이어짐 | 같음 | 슬럼 가까운 층: 판잣집 벽·배관·늘어진 전선, 작은 등불 |
| `far_foundry` | 960×540 | 녹슨 주황·짙은 갈색 / 용광로의 밝은 주황 | 공장: 굴뚝과 철골 들보가 겹겹이, 연기, 용광로 빛 |
| `mid_foundry` | 1440×540, 좌우 이어짐 | 같음 | 공장 가까운 층: 배관 다발·크레인·체인, 호박색 작업등 |
| `far_haze` | 960×540 | 검푸른 청록 / 밝은 청록 결정 빛 | 탑: 결정이 자란 거대한 탑 내부, 위로 끝없이 |
| `mid_haze` | 1440×540, 좌우 이어짐 | 같음 | 탑 가까운 층: 결정 기둥·철골 난간·감시 장치 |

- **픽셀 아트**로 그린다(이번 작업은 캐릭터와 달리 처음부터 픽셀). 960×540 한 장에 픽셀 크기 1로, 흐림·반투명 없음(알파 0·255), 장마다 32색 이하.
- 게임에서 싸우는 자리(세로 가운데 아래쪽 2/3)는 명암을 낮고 단순하게: 캐릭터(흰 머리·청록)가 묻히지 않게.
- 지금 배경(`assets/backgrounds/far_*.png`, `mid_*.png`)은 1920 해상도 AI 그림이라 픽셀 크기가 다르다. 구도만 참고하고 새로 그린다.
- 새 폴더 `assets/sprites/forge/backdrops_v6/`. 기존 파일은 건드리지 않는다(적용은 Claude Code).

## 절차
슬럼(원경→중경) → 공장 → 탑. 같은 이미지 최대 3번. 확인용으로 각 구역 원경 위에 중경을 겹친 미리보기와, 중경 두 장을 이어 붙인 미리보기.
보고서 `docs/codex/reports/T49.md`, 상태 `review`.

## 합격 기준
- [ ] 구역마다 지배색 하나가 분명하다 (세 구역이 색만 봐도 구별된다)
- [ ] 픽셀 크기 1, 알파 0·255, 32색 이하 (`python tools/check_sprites.py`가 맞지 않으면 보고서에 색 수·알파를 직접 적는다)
- [ ] 중경 좌우가 이어진다
- [ ] 싸우는 자리가 단순하고 어둡다
- [ ] 보고서에 솔직하게
