# 2차 발표 영상 촬영 가이드 (2026-11-17)

대본은 `docs/script_2nd.md`, 발표자료는 `docs/presentation_2nd.pptx`(2장). 이 문서는 **녹화부터 제출까지의 순서**다.
2026-11-17에 확인한 것: 처음부터 실행(Title → Play) 13초간 오류 없이 돌았고, 전체 테스트 148개가 통과했다. PPT 2장은 렌더링해서 글자 겹침·잘림이 없음을 확인했다. **소리와 실제 조작 감은 사람이 확인해야 한다.**

## 1. 녹화 전 준비 (5분)
1. `git pull`로 최신을 받고 `python tests/run_all.py`가 모두 통과하는지 본다.
2. 해상도 **1920×1080**: 게임 창이 화면에 다 들어와야 한다(작업 표시줄에 가려지지 않게). 모니터가 1080p면 게임 창이 작업 표시줄에 닿을 수 있으니 확인한다.
3. 알림·메신저를 끄고, 다른 창(개인 메모, 메신저)이 녹화 영역에 안 보이게 한다.
4. 소리: 효과음이 들리는지, 마이크 입력이 잡히는지 시험 녹화 5초로 확인한다.

## 2. 녹화 도구 (Windows)
| 도구 | 방법 | 비고 |
|---|---|---|
| Xbox Game Bar | `Win + G` → 녹화, 또는 `Win + Alt + R`로 시작/종료 | 설치 불필요. 게임 창 한 개만 녹화한다. 마이크 켜기는 Game Bar 설정에서 |
| OBS Studio | 장면에 "창 캡처"(게임), "오디오 출력 캡처", "마이크" | 화면과 PPT를 한 영상으로 만들 때 편하다 (무료) |
- PPT 2장 구간은 슬라이드쇼(`F5`)를 띄워 녹화하고, 이어서 게임 창을 녹화한다. 두 구간을 따로 녹화해 이어 붙여도 된다(영상 편집 도구 필요).

| 0:00~0:15 | PPT 1장 | 게임 설명 낭독 |
| 0:15~0:40 | PPT 2장 | 계획 대비 진행 상황, 기획 변경 낭독 |

## 4. 데모 순서 (50초)와 조작
실행: `python src/main.py` → 타이틀에서 아무 키.
1. **방 1(허브)**: 마우스로 겨누어 좌클릭. 위·대각선으로 휘두르고 충격선이 퍼진다. `F1` → `F3`을 여러 번 눌러 게이지를 올리면 타수가 늘어나는 것이 보인다. (약 12초)
2. **대시**: `Shift`. 지나온 길을 베고 잔상이 남는다. 얇은 발판 위에서 마우스를 아래에 두고 대시하면 뚫고 내려간다. 적을 모두 처치하면 문이 열리고 문 색(노랑 황금방, 파랑 정비방, 빨강 보스)이 보인다. (약 12초)
3. **황금방**(허브 → 교차로 → 위 문): `F`로 아이템 획득. **정비방**(허브 아래 문): 조각으로 구매. 그 뒤 `F1` → `F3`을 계속 눌러 100%를 넘기면 **오버로드**(화면 번쩍임, 기절). (약 14초)
4. **보스 방**(허브 오른쪽 길 끝): `E`로 강화한 뒤 크래셔와 싸운다. 충격파는 점프, 돌진은 대시로 피한다. 처치하면 탈출 화면. (약 12초)
- 시간이 모자라면 3번(황금방·정비방)을 줄이고, 남으면 방 2의 적 두 종을 보여 준다.

## 5. 리허설 요령
- **전체를 한 번 끝까지 연습**한다(시간 재기). 낭독은 425자라 약 80초 분량이라, 데모 조작 시간과 겹치지 않게 데모 중에는 짧게만 말한다.
- 조작이 막히면 `Esc`로 일시정지하지 말고 다시 시도한다(일시정지 화면이 녹화에 들어간다).
- 보스는 체력이 많아 시간이 걸린다. 연습할 때 몇 초 걸리는지 확인하고, 오래 걸리면 보스 방에서 E 강화 일격을 먼저 쓰는 모습만 보여 준다.
