## 2. 프롬프트 요약 및 시도 횟수
- **공통 조건**: 어두운 무채색 의상(차콜·슬레이트·흑연), 포인트 색은 헤이즈 청록(`#00F0E0`) 단일 사용, 선 없는 평면 색면 + 재질별 3단계 음영(왼쪽 위 광원), 마젠타 단색 배경(`#FF00FF`), 여백 확보·몸 잘림 없음, 금지 요소(흰 머리+붉은 포인트, 여우 귀·꼬리, 쿠나이, 동양 사원풍) 배제.
- **A안 (`hero_A_side` 3회, `hero_A_sheet` 2회)**: 삐죽하게 뒤로 젖힌 어두운 머리, 크롭 작업 재킷, 허리 청록 헤이즈 바이알, 뒤로 길게 흩날리며 끝이 청록 헤이즈 연기로 흩어지는 이중 머플러, 철파이프.
- **B안 (`hero_B_side` 3회, `hero_B_sheet` 1회)**: 뒤로 넘긴 어두운 머리, 얼굴 하반부를 가리는 헤이즈 흡입 마스크와 목으로 이어지는 발광 청록 관, 찢어져 뒤로 나부끼는 롱코트 자락, 철파이프.
- **C안 (`hero_C_side` 2회, `hero_C_sheet` 1회)**: 깊게 눌러쓴 각진 후드와 그림자 속 청록 눈, 뒤로 날리는 후드 끈, 등에 멘 소형 원통 헤이즈 탱크와 팔목 커프로 이어지는 발광 청록 호스, 철파이프.
- **축소 확인(`*_small.png`)**: 각 `*_side.png`를 Pillow로 1/24(43×43, BOX) 축소한 뒤 1024×1024(NEAREST)로 확대해 41px 전후 실루엣 가독성을 확인.

- [x] 세 안의 실루엣이 서로 확실히 다르다 (A: 크롭 재킷+이중 긴 머플러 / B: 롱코트 자락+마스크 관 / C: 삼각 후드 판초+등 탱크·호스)
- [x] 세 안 모두 공통 조건(어두운 몸, 청록 포인트, 흩날리는 요소)을 지킨다
- [x] 금지 요소가 없다 (흰 머리·붉은 포인트·여우 귀/꼬리·쿠나이·동양 사원 소재 없음)
- [x] 옆모습이 단색 마젠타 배경·몸 잘림 없음으로 PixelLab 기준 그림으로 쓸 수 있다
- [x] 모델명 미제공 사실과 프롬프트 요약을 기록했다

## 4. 기준과 달라진 점 및 해결 못한 문제
1. **외곽선 잔존**: "선 없는 평면 색면"을 요청했으나 A안·B안의 얼굴·바지·부츠·파이프 경계와 시트 정면 그림 일부에 얇은 어두운 윤곽선이 남았다(C안 옆모습이 가장 선 없는 평면 색면에 가깝다).
2. **마젠타 배경 미세 편차 및 JPEG 경유**: 이미지 생성 도구가 `.jpg`로 저장해 PNG로 무손실 변환했으며, 배경색이 정확히 `(255, 0, 255)`가 아니라 균일한 밝은 마젠타(A: `255,19,252`, B: `245,39,238`, C: `252,39,251`)로 출력되었다. 배경 제거 시 색상 허용치(tolerance)가 필요하다.
3. **A안 옆모습 몸통 각도 및 시트 사소한 디테일**: `hero_A_side.png`는 머리와 시선은 오른쪽 완전 옆모습이지만 상체·골반이 약간 3/4 뒤돌아본 각도다. 또한 이미지 생성 쿼터 소진(429)으로 시트 추가 다듬기를 중단해 `hero_A_sheet.png` 달리기 실루엣 안에 작은 청록 눈 점이 남아 있고 색표 칸에 얇은 테두리가 있으며, `hero_B_sheet.png` 6번째 색표 칸에 미세한 얼룩이 남아 있다.
4. **C안 축소 시 후드 끈 가독성**: `hero_C_small.png`(43×43)에서 탱크·호스·후드 삼각 실루엣은 매우 또렷하지만, 얇은 후드 끈 두 가닥은 1px 미만으로 옅어진다. C안을 선택해 마스터로 갈 경우 끈을 더 굵게 잡거나 호스 움직임을 주 2차 요소로 강조하는 편이 좋다.
