## 2. 프롬프트 요약 및 시도 횟수
- **주인공 (`hero_portrait.png`, 1회 성공)**: `hero_A_side.png`를 참조하되 G01 확정 사항에 따라 **흰 머리(순백/은백 삐죽머리)**로 변경. 청록 눈(`#00F0E0`), 피곤하지만 날카로운 표정, 어두운 차콜 작업 재킷과 청록 헤이즈 연기가 감도는 어두운 머플러, 가슴 위 3/4 구도(오른쪽 안쪽 시선), 애니풍 선화 + 3단계 셀 음영, 마젠타 단색 배경(`#FF00FF`).

## 3. 해결 못한 문제
- **이미지 생성 모델 할당량 소진 (`429 RESOURCE_EXHAUSTED` / `QUOTA_EXHAUSTED`)**: `gemini-3.1-flash-image` 할당량이 소진되어 `2026-11-23 21:02:25 KST` (`2026-11-23T12:02:25Z`) 이후에 초기화됩니다. 초기화 후 나머지 NPC 3장(및 G02·G03)을 이어서 생성해야 합니다.
- **마젠타 배경 미세 편차**: `hero_portrait.png`는 생성 도구가 JPG로 출력한 이미지를 PNG로 변환했으며, 모서리 배경색은 `(253, 6, 247)`으로 정확한 `#FF00FF`와 소폭 차이가 있어 배경 제거 시 색상 허용치(tolerance)가 필요합니다.
