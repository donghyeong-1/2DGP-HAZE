## 3. 제작 방식, 바꾼 것 / 그대로 둔 것, 프롬프트·모델 기록

### 제작 방식 (원본 보존 + 인물 국소 편집)
`assets/sprites/forge/`에 남아 있던 **양자화 전 1920×1080 원본(`conformed/background.png`)**을 그대로 바탕으로 썼다.
1. 첫 시험(`credits_1` 전체 16:9 편집 1차: `raw/credits_1_full_attempt1.jpg`)에서는 모델이 전신 참조 이미지의 크기와 걸음 포즈, 검은 외곽선을 과하게 따라와 주인공이 화면 높이의 73%로 커지고 절벽이 아래로 밀리는 문제가 발생했다(전체 편집 2차 시도는 서버 `HTTP 503 No capacity available for model gemini-3.1-flash-image`로 중단).
2. 이를 해결하기 위해 각 1920×1080 원본에서 **인물과 주변 광원·그림자·여백을 넉넉히 포함한 크롭**을 잘라 `image-generator`(`gemini-3.1-flash-image`)로 **인물만 선 없는 평면 색면 화풍으로 교체**한 뒤, 경계 링 정렬(오차 `dx=0, dy=0~1px`, 경계 MAE `1.44~3.84/255`)과 코사인 페더 마스크로 원본 1920×1080 배경에 무봉합 합성했다.
3. 마지막으로 기존 T11·T35와 **완전히 동일한 명령**(`hibit_plate.py plate --size 1920x1080 --colors 32 --smooth 0 --preview-scale 1`)으로 32색 1배 마감을 수행해 배경·인물 전체가 하나의 팔레트와 질감으로 어우러지게 했다.

### 공통으로 바꾼 것 vs 그대로 둔 것
- **바꾼 것 (인물 디자인)**:
  - **제거**: 짧은 죄수복 반소매, 맨팔, 청록 줄무늬 팔띠·손목 붕대, 허리의 파란 천 리본, 맨살이 드러나는 찢어진 바지, 무기(모든 장면 맨손).
  - **반영 (현재 v6 N-09)**: 더 길고 뾰족하게 뻗친 순백색 머리, 차가운 창백한 피부(`n09_1.png`·`hero_portrait.png` 기준), 청록 눈빛(얼굴이 보이는 장면), 목을 높게 감싼 짙은 남색·차콜 머플러와 끝이 청록 불꽃/안개처럼 해진 두 가닥 꼬리, 주머니가 달린 어두운 긴소매 크롭 전술 재킷, 허리 옆 소형 청록 헤이즈 바이알, 온전한 어두운 카고 바지와 검은 전투화.
- **그대로 둔 것**:
  - 4장 모두 **구도, 배경 건축물·지형·구름·하늘·결정, 빛 방향과 색온도, 선 없는 평면 색면 화풍, 인물의 화면 내 위치·크기·자세, 글자 및 UI 안전 영역**을 원본 1920×1080 그대로 유지했다.

## 5. 스스로 본 약점 (솔직한 검수 메모)

1. **`credits_3.png` 32색 양자화 시 머플러 끝 청록색의 하늘색 수렴**: 맑은 아침 도시 배경(하늘·지붕·녹지·그림자)이 32색 팔레트의 대부분을 차지해, 작은 인물 머플러 끝의 청록 불꽃이 원화의 선명한 시안(`#00F0E0`)보다 밝은 하늘색(`#7ebafb`~`#62a4f0`)으로 매핑되었다. 그래도 원경에서 머플러 꼬리 실루엣과 차가운 포인트 색으로 충분히 읽히고, 맑은 낮 조명에도 자연스럽다.
2. **`credits_1.png` 머플러 끝과 좌측 청록 결정의 근접**: 왼쪽으로 길게 뻗은 머플러 꼬리의 청록 불꽃 끝이 좌측 절벽 위 청록 결정 바로 앞을 지나가 시각적으로 가깝다. 어두운 머플러 천과 명도 차가 있어 실루엣은 읽히지만, 가까이 보면 좌측 결정과 청록 포인트가 한 구역에 몰린 인상이 있다.
3. **`screen_ending.png` 바닥 그림자의 머플러 꼬리 미반영**: `credits_3.png`는 햇빛 아래 길게 뻗은 그림자에 머플러 두 가닥까지 그려졌으나, `screen_ending.png`는 기존 원본의 바닥 그림자 실루엣을 유지해 왼쪽으로 날리는 머플러 꼬리 그림자가 바닥에 드리워지지 않았다(문 안쪽 왼쪽 벽면 그림자 쪽으로 뻗어 있어 눈에 띄지는 않으나 엄밀한 광원 정합 면에서 아쉬운 점).
4. **`screen_death.png`의 보관인 맡기기 5~6칸 이상일 때 좌측 끝 근접**: `ending_mode.py`의 보관인 칸(`CHOOSE_GAP=88`, 중앙 `x=960`)이 4칸(아이템 3개+없음) 이하일 때는 `x=792`부터 시작해 머리 끝(`x=766`)과 26px 떨어져 전혀 겹치지 않으나, 5~6칸이 열리면(`x=748`~`704`) 기존 그림(`x=764`)과 마찬가지로 첫 칸과 뒤 어둠이 흰 머리 오른쪽 끝 18~62px에 걸친다.
5. **`credits_2.png`(유지 결정)의 미세 차이**: 세 NPC 모두 현재 게임 초상화·도트와 동일 인물로 명백히 읽혀 다시 그리지 않았으나, 기록관 셔츠 소매가 현재 도트/초상화(접은 칼라 셔츠+수인표)보다 해져 있고 정비사 의수 방향이 초상화(`mechanic_1.png`, 왼팔) 대신 인게임 도트(`npc_mechanic_idle_1.png`, 오른팔)를 따른다는 기존 차이가 그대로 남는다.
