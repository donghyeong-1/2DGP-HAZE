# G01 새 주인공 디자인 시안 3안

먼저 `docs/gemini/COMMON.md`를 읽고 그 규칙을 따른다.

## 배경
v6 대규모 개편(`docs/plan_v6.md`)에서 주인공을 새로 만든다. 지금 주인공(`assets/sprites/unified/n09_idle_1.png`, 코드네임 "화이트", 이름은 임시)은
평범한 옷차림이라 작게 보이면 개성이 없다. 목표는 **작게 보여도 스타일리시한 주인공**이다.
슬럼 출신의 헤이즈 중독자로, 헤이즈를 써서 강해지지만 끊으면 쓰러진다(게이지 0%에서 사망, 100%에서 폭주).
주 무기는 철파이프(그 밖에 식칼·건틀릿·사슬을 바꿔 든다).

## 공통 조건
- 몸은 어두운 무채색 계열, **포인트 색은 헤이즈 청록 하나**(눈·빛나는 부분). 어두운 방에서도 바로 찾혀야 한다.
- **흩날리는 2차 움직임 요소 하나**를 반드시 넣는다(달리기·대시·공격 때 뒤로 끌린다).
- 머리 모양·옷 윤곽만으로 알아볼 수 있는 실루엣. 41px로 줄여도 읽히는 큰 모양.
- 금지: 흰 머리 + 붉은 포인트 조합, 여우 귀·꼬리, 쿠나이, 동양 사원풍 의상 (INARI와 겹침).

## 세 안 (서로 확실히 다르게)
| 안 | 핵심 | 흩날리는 요소 |
|---|---|---|
| A | 짧은 작업 재킷 + 긴 머플러. 머플러 끝이 헤이즈 연기처럼 흩어진다 | 머플러 |
| B | 찢어진 롱코트 + 얼굴 반을 가리는 헤이즈 흡입 마스크(관이 목으로 이어짐) | 코트 자락 |
| C | 후드 + 등에 멘 작은 헤이즈 탱크, 탱크에서 팔로 이어지는 빛나는 호스 | 후드 끈·호스 |

## 만들 것 (안마다)
1. `hero_<A|B|C>_side.png`: 오른쪽 옆모습 전신, 서 있는 자세, 철파이프를 든다. 마젠타 배경 1024×1024 이상.
2. `hero_<A|B|C>_sheet.png`: 같은 인물의 정면 전신 + 달리기 자세 실루엣(검은 덩어리) + 색표(6~10색). 한 장에.
3. `hero_<A|B|C>_small.png`: 1번을 **가로세로 1/24로 줄였다가 다시 키운 확인용** 그림(작게 봐도 알아보는지).
   직접 줄이기 어려우면 생략하고 보고서에 적는다(Claude Code가 만든다).

새 폴더: `assets/sprites/gemini/hero_concepts_v1/`. 안마다 최대 3번 시도.
