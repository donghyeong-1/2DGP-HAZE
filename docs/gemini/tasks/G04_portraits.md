# G04 대화 초상화 (주인공 + 은신처 NPC 3)

먼저 `docs/gemini/COMMON.md`를 읽고 그 규칙을 따른다.

## 배경
INARI처럼 대화 때 작은 픽셀 말풍선 옆에 **고해상도 상반신 초상화**를 띄운다(`docs/plan_v6.md`). 초상화는 픽셀 아트가 아니다.
보스 초상화는 G02 디자인이 확정된 뒤 따로 만든다.

## 합격 기준
- [ ] 게임 속 모습(픽셀)과 같은 인물로 알아볼 수 있다
- [ ] 네 장의 화풍·구도·크기가 같다
- [ ] 마젠타 배경, 보고서에 모델명·프롬프트

## 검토 (2026-11-26, Claude Code)
- **합격 기준 통과**: 여섯 장의 화풍·구도·크기가 같고, 게임 속 모습(11/25에 PixelLab으로 바꾼 새 몸 그림)과 같은 인물로 알아볼 수 있다
  (정비사: 올림머리·고글·결정 의수·렌치·멜빵 / 보관인: 두건·수염·등짐 / 기록관: 안경·연필·장부). 주인공 표정 3장은 구도가 거의 겹친다.
  마젠타 배경은 정확한 (255,0,255)가 아니지만 색 허용치로 지워지고, 기록관 안경알 안쪽 마젠타도 같이 지워진다(시험: 100px로 줄여 32색, 2배).
- **게임 크기에서 본 차이** (`shots/review/g04_game_size.png`: 윗줄 G04, 아랫줄 지금 게임의 초상화): G04의 NPC 셋은 살색·옷이 밝고 채도가 높으며 검은 외곽선이 굵다.
  지금 초상화(11/25 PixelLab, 주인공 초상화를 화풍 기준으로 생성)는 어둡고 탁한 색이라 주인공 초상화·어두운 UI와 톤이 맞고, 얼굴이 더 크게 잡혀 있으며 **표정이 두 장씩** 있다
  (정비사 씩 웃음, 보관인 걱정, 기록관 놀람. 게임은 인물마다 표정 2장을 쓴다). G04의 NPC는 표정이 한 장뿐이다.
- 주인공의 분노·피격 표정은 잘 나왔지만 지금 게임에는 쓸 칸이 없다(대화창의 표정 2는 '강화를 샀을 때의 결의'다).
- **Claude Code 추천**: 게임 초상화는 지금 것(PixelLab)을 유지하고, G04는 고해상도 원화로 보관한다(발표 자료의 인물 소개 등에 쓸 수 있다). **2026-11-26 사용자 결정: "지금 것이 좋네" -> 게임 초상화는 그대로, G04의 새 5장은 원화로 보관.**
