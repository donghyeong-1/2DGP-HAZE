# G06 UI 부품 (C안 결정형, A안 크기)

먼저 `docs/gemini/COMMON.md`를 읽고 그 규칙을 따른다. 단, 아래 "이 작업만의 예외"가 COMMON보다 우선한다.

## 배경
- G05에서 사용자가 **C안(결정형)을 A안 크기로** 골랐다(2026-11-24). 기준 그림: `assets/sprites/gemini/ui_concepts_v1/ui_C2_hud.png`(G05 2차), `ui_C_cards.png`, 그리고 장식 참고로 `ui_C_hud.png`·`ui_C_pause.png`.
- 이번에는 화면 시안이 아니라 **게임에 넣을 부품**을 그린다. 부품 시트를 받으면 Claude Code가 목표 크기로 줄이고(최근접), 색을 팔레트에 맞추고, 9칸 판으로 잘라 코드(`src/hud_kit.py`, `src/ui.py`)에 연결한다.
- 그래서 **정확한 픽셀 크기보다 모양·비율·색 면이 분명한 것**이 중요하다.

## G05 2차 검토에서 나온 지적 (2026-11-25 Claude Code, 부품에서 반복하지 않는다)
`ui_C2_hud.png`와 `ui_C_cards.png`는 방향이 맞아 그대로 기준 그림으로 쓴다(크기는 재 보니 체력·미니맵·무기함 모두 A안 이하였다). 다만 부품에서는 아래를 지킨다.
- **보통 카드 테두리**: 시안은 두껍고 모서리가 둥글었다. 부품은 **얇은 1점 흰 선 + 사선으로 자른 모서리**(HUD 판과 같은 말투)로 그린다. 결정 없음.
- **하트 아이콘**: 시안의 하트가 A안보다 조금 컸다. 아래 표의 목표 크기를 지킨다.
- **떠도는 선·글자 금지**: 카드 시안의 왼쪽 카드 옆에 흰 세로줄이 하나 생겼다. 부품 시트에는 부품과 번호 말고 아무것도 그리지 않는다.
- **색 번짐**: 시안의 막대·카드 안쪽이 수천 가지 색이었다(JPG 압축). 부품은 아래 팔레트 색의 **큰 평평한 면**으로만 그린다. 남은 번짐은 Claude Code가 팔레트로 맞춘다.
- 게이지 높이는 `ui_C2_hud.png` 그대로가 좋다(가장 눈에 띄는 UI).

## 이 작업만의 예외 (COMMON 3절보다 우선)
- UI 부품이므로 **픽셀 아트처럼 평평한 색 면**으로 그린다. 그라데이션·빛 번짐·반투명·사진 질감 금지.
- **크게 그린다**: 아래 표의 "목표 크기"(960×540 격자 기준 픽셀)를 **8배**로 그린다. 즉 목표 크기의 1점 = 8×8px 덩어리. 선의 굵기도 8px의 배수.
- 배경은 마젠타(#FF00FF) 단색. 부품끼리 32px 이상 떨어뜨리고, 부품마다 아래에 작은 번호만 적는다(설명 글자는 보고서에).
- 팔레트(이 색만 쓴다. 부품마다 꼭 필요한 만큼만):

| 이름 | 색 | 쓰는 곳 |
|---|---|---|
| 남색 1 / 2 / 3 | #0d121f / #161e31 / #222c45 | 판 속, 빈 칸, 그림자 |
| 흰색 / 옅은 회색 | #f2f6fa / #8c98b0 | 선, 꺼진 칸 테두리 |
| 청록 밝음 / 기본 / 그림자 | #9ff7ee / #2ee6d6 / #0b6a74 | 결정, 강조, 고른 것 |
| 빨강 / 빨강 그림자 | #e0404c / #8a1f2c | 체력, 페이드 구간 |
| 주황 | #ff9a3c | 위험 구간, 경고 |
| 금색 / 금색 그림자 | #ffd36e / #9a6a1c | **전설(합성) 카드에만** |

## 합격 기준
- [ ] 4장 모두 마젠타 바탕, 부품이 서로 떨어져 있고 번호가 있다
- [ ] 팔레트 밖의 색이 없다 (금색은 전설 카드에만)
- [ ] 8배 덩어리로 그려져 목표 크기로 줄였을 때 모양이 무너지지 않는다 (가장 작은 점 = 8×8px)
- [ ] 9칸 판 부품은 변을 이어 붙여도 무늬가 끊기지 않는다
- [ ] 장식은 C안, 크기·두께는 A안 수준 (결정 장식은 게이지 끝·든 무기 칸·하트 옆·판 모서리·카드 등급에만)
- [ ] 보고서에 모델명·프롬프트·시도 횟수, 부품 번호 ↔ 이름 표
