# v5 계획: 재미 요소 (2026-11-22, 하데스·스컬·던그리드·산나비 참고)

사용자 판단: "전체 퀄리티와 재미 요소가 많이 부족하다. 항상 똑같은 적만 본다."
목표: 판마다 다른 빌드, 구역마다 새 적, 크고 특색 있는 보스. 그대로 베끼지 않고 **헤이즈 게이지**와 묶는다.
담당 **CC** = Claude Code(코드·코드 그림·소리), **CX** = Codex(이미지 생성), **U** = 사용자. 남은 기간 약 3주(~12월 둘째 주).
확정된 것은 아직 없다. 사용자가 고른 순서대로 진행하고, 기획이 바뀌면 `docs/changes_from_plan.md`에 적는다.

## 1. 새 적 — 구역이 바뀌면 새 적이 나온다 (사용자 요청)
지금은 세 구역 모두 슬럼·투척병·사냥개·간수 4종만 섞어 쓴다. 구역마다 그 구역에만 나오는 적 2종을 더한다.

| 구역 | 지금 | 더할 적 (안) | 새로 생기는 대응 |
|---|---|---|---|
| 1 슬럼 | 슬럼·투척병·사냥개 | **헤이즈 쥐 떼**(작고 빠른 무리, 한 대에 죽음) / **누더기 무당**(뒤에서 다른 적에게 보호막) | 광역 공격의 가치, 우선 처치 대상 |
| 2 공장 | + 간수 | **용접 드론**(날아다님, 짧은 직선 불꽃) / **자폭 수레**(달려와 터짐, 맞혀서 되돌려 보낼 수 있음) | 위로 조준(마우스 조준이 살아남), 받아치기 |
| 3 탑 | + 간수 | **감시 눈**(벽에 붙어 레이저로 바닥을 훑음, 부술 수 있음) / **결정 기사**(순간이동해 베고, 맞으면 결정 파편을 흩뿌림) / **헤이즈 망령**(벽을 통과, 닿으면 게이지를 빼앗음) | 회피 타이밍, 게이지 관리 |

- 날아다니는 적(드론·눈·망령)은 중력 없는 새 이동(목표점으로 날아감·벽 통과 여부)이 필요하다(CC).
- 그림: 적마다 대기·이동·공격 2~3·피격·쓰러짐 약 10~14장(CX, 적 하나가 작업 하나).

## 2. 보스 — 크고, 방을 쓰고, 헤이즈 농도를 바꾼다 (사용자 요청)
### 2-1. 기존 보스에 페이즈 패턴 더하기 (그림이 거의 필요 없어 빠르다)
- **크래셔(공장)** 2페이즈: 천장에서 고철 기둥을 떨어뜨려 **발판이 되는 지형**을 만든다(올라타면 피할 수 있고, 다시 부순다) / 바닥 **용광로 배기구**가 차례로 분출(지형 위험) / **배기 펌프**: 방을 고농도로 만들어 게이지가 계속 오른다 → 방의 배관 밸브를 쳐서 끈다.
- **아크(탑)** 2·3페이즈: 방에 **농도 띠**를 깐다 — 짙은 띠(게이지 상승)와 맑은 띠(게이지 하강)가 천천히 움직여, 서 있는 자리로 게이지를 지켜야 한다 / 결정 기둥을 세워 **벽처럼 막고**, 부수면 게이지를 흡수 / 3페이즈에 발판 일부가 무너진다.

### 2-2. 새 거대 보스: **헤이즈 심장** (최종 결전, 화면을 채우는 크기)
- 탑 꼭대기, 아크를 쓰러뜨리면 방 뒤편 벽이 열리며 등장(아크의 진짜 모습). 화면 위쪽 절반을 차지하는 **심장(본체)** + 따로 움직이는 **거대한 기계 손 두 개**(손마다 체력·피격 판정).
- 패턴: 손 내려치기(충격파) / 손바닥 레이저 훑기 / 결정 비 / **농도 파동**(방 전체 게이지가 오르내리는 파도: 위험·페이드 사이를 오가게 해 게이지 줄타기를 시험) / 손 두 개를 기절시키면 심장이 열려 약점 노출.
- 페이즈가 오를 때마다 방이 바뀐다: 발판이 솟고, 바닥이 헤이즈로 잠기고(밟으면 게이지 상승), 마지막엔 심장이 직접 내려온다.
- 그림: 본체 1(큰 그림, 여닫는 약점 2~3장), 손 대기·내려치기·레이저 자세 6~8장, 등장·쓰러짐 연출(CX 2~3 작업). 다부위 보스 코드·패턴(CC).

## 3. 판마다 다른 빌드 (앞서 정리한 1순위 묶음)
- **방 보상 미리보기**: 문 위 아이콘(조각·회복·변이·결정·무기 강화)을 보고 길을 고른다.
- **헤이즈 변이 3택**: 방을 깨면 셋 중 하나. 게이지 구간과 묶인 효과(예: 각성 구간 대시가 충격파, 페이드 공격 흡혈), 같은 계열 2~3개면 시너지. 처음엔 변이 12~15개, 시너지 3~4개.
- **저스트 대시**: 맞기 직전 대시 -> 짧은 슬로 모션 + 게이지 상승.
- 이후: 무기 교체 공격(스컬), 부서지는 지물, 사슬 갈고리 이동(산나비), 난이도 서약(하데스).

## 4. 빨리 효과 나는 것 (UI·UX·소리·에셋)
1. 자주 나는 효과음 3버전 번갈아 + 메뉴 전용 소리
2. 공격·대시 입력을 0.1초 미리 받아 두기
3. 사망 화면 "무엇에 죽었나"
4. 구역별 날씨 입자(비·불티·헤이즈 입자) + 빛 번짐
5. 적의 얇은 밝은 테두리 + 강한 공격 예고 표시
6. 아이템을 얻을 때 이름·효과 띠

큰 UI: 카드형 선택 창(변이 3택에 씀), 일시정지 탭(빌드·지도·조작·설정), 전체 지도, 전경 실루엣 층(CX), 전투 음악 층.
