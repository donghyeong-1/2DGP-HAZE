# v7 계획: 무기·증강 개편 + 이펙트·연출 + 보스·적 다듬기 (2026-11-23 초안, 증강 표는 사용자 검사 대기)

목표: 플레이스타일을 고를 수 있는 스타일리시한 전투. 하데스처럼 무기마다 갈래가 있고, 고른 갈래에 맞는 증강이 더 자주 나오며,
갈래를 키우면 무기가 **진화**해 공격 방식과 이펙트가 바뀐다. 두 무기의 갈래가 만나면 **합성 증강**이 열린다.
이펙트는 INARI처럼 단색 면·흰 섬광·블룸으로 다시 만든다(`docs/plan_v6.md`의 화풍과 같이). 마감은 12월 둘째 주.

## 1. 무기 4종 (식칼 → 쌍권총)
| 무기 | 기본 | 손맛 |
|---|---|---|
| 철파이프 | 빠른 3연타 근접 | 연타·이동 베기·공중 |
| **쌍권총** (식칼 대체) | 좌우 번갈아 연사, 이동·점프하며 쏨 | 거리 유지, 도탄, 대시 사격 |
| 쌍 건틀릿 | 누르는 동안 충전, 떼면 강타 | 단일 고피해, 넉백, 충격파 |

- 무기는 지금처럼 기본 철파이프 + 두 번째 칸 하나(은신처 무기 걸이·황금방).

## 2. 증강(헤이즈 변이 v2)
### 구조
- **갈래(path)**: 무기마다 2~3개, 공통 갈래 2개(대시·게이지). 증강마다 갈래가 하나 붙는다.
- **기본 증강 → 진화 → 합성** 3단.
  - 기본: 갈래의 수치·작은 효과 (예: 공속 +15%).
  - **진화**: 같은 갈래 기본 2개를 가지면 나올 수 있다. 공격 방식과 이펙트가 바뀐다 (예: 사슬이 소용돌이로 적을 모음).
  - **합성**: 두 무기(또는 무기+공통)의 진화가 하나씩 있으면 나올 수 있다 (예: 사슬로 모은 순간 건틀릿 완충 강타가 자동).
- **나오는 확률**: 가진 갈래는 무게 ×3, 들고 있는 무기의 갈래 ×2, 안 맞는 무기 갈래는 거의 안 나온다. 셋 중 하나는 늘 새 갈래(빌드 바꾸기 여지).
- 지금 게이지 계열 12종(각성·위험·페이드·강화)은 **공통 갈래 '게이지'**로 흡수한다(헤이즈 정체성 유지).

### 갈래 (사용자 결정: 무기마다 3갈래 전부, 검사 후 구현)
갈래마다 **기본 증강 3개 + 진화 1개**. 진화는 같은 갈래 기본 2개를 가지면 카드에 나온다.
수치는 초안이고 구현 때 balance-sim으로 맞춘다.

#### 철파이프 (근접 연타)
| 갈래 | 기본 증강 3 | 진화 (공격·이펙트가 바뀜) |
|---|---|---|
| **연타** (공속) | 공속 +15% / 3타째 피해 +30% / 연속으로 맞힐 때마다 다음 타 빨라짐(최대 3단) | **난타**: 4·5타가 생기고 마지막 타가 회전 베기 (흰 원형 궤적, 주변 전체) |
| **공중** (점프 공격) | 공중 공격 피해 +25% / 공중에서 맞히면 잠깐 체공 / 점프 공격이 적을 살짝 띄움 | **낙뢰 내려찍기**: 내려찍기 착지에 청록 번개 기둥 + 충격파, 주변 적을 띄움 |
| **이동 베기** (대시 공격) | 대시 공격 피해 +30% / 대시 공격 거리 +40% / 대시로 벤 적마다 대시 충전 빨라짐 | **섬광 베기**: 대시 공격이 화면을 가로지르는 직선 베기, 지나간 적에게 0.3초 뒤 번쩍하며 지연 피해 |

#### 쌍권총 (원거리, 식칼 대체)
| 갈래 | 기본 증강 3 | 진화 |
|---|---|---|
| **연사** | 연사 속도 +20% / 탄 +1 (부채꼴) / 멈춰 서서 쏘면 연사 +30% | **난사**: 누르고 있으면 끊김 없는 탄막, 총구 섬광 연속·탄피 |
| **도탄** | 총알이 벽에 1번 반사 / 반사한 총알 피해 +30% / 반사 +1번 | **도탄 사슬**: 맞힌 총알이 가까운 적으로 튕김(최대 3), 빛줄기 잔상 |
| **대시 사격** | 대시 중 자동 사격 / 대시 직후 0.5초 연사 2배 / 적 공격을 대시로 피하면 강화탄 장전 | **탄막 회피**: 대시가 끝난 자리에 8방향 원형 탄막 |

#### 쌍 건틀릿 (충전 강타)
| 갈래 | 기본 증강 3 | 진화 |
|---|---|---|

| **충돌** (넉백) | 넉백 +40% / 날아간 적이 벽에 부딪히면 피해 / 날아간 적 0.5초 기절 | **연쇄 충돌**: 날아간 적이 부딪힌 적도 같이 날아감 (볼링) |
| **반격** | 적이 공격 예고 중일 때 강타하면 피해 2배 / 반격 성공 시 0.3초 무적 / 반격 성공 시 게이지 +5% | **역류**: 반격 순간 흰 고리 충격파가 적 투사체를 되돌려 보냄 |

|---|---|---|

| **게이지** (헤이즈) | 지금 변이 12종(각성·위험·페이드·강화 계열)을 그대로 둔다 | 계열 시너지(같은 계열 2개, 지금 규칙) |

#### 합성 (두 진화가 만나면, 1차 8종)
철파이프는 늘 들고 있고 두 번째 칸은 하나라서, 합성은 파이프×두 번째 무기, 무기×공통 위주다.
| 합성 | 필요 | 효과 |
|---|---|---|
| 끌어모아 한 방 | 사슬 소용돌이 + 건틀릿 헤이즈 붕괴 | 소용돌이가 모은 자리에 완충 강타가 자동으로 떨어진다 |
| 빛 그물 | 사슬 반사 + 권총 도탄 사슬 | 총알이 사슬의 꺾인 길을 따라 튕긴다 |
| 분신 연타 | 파이프 난타 + 잔영 대시 | 분신이 난타 5타를 따라 친다 |
| 볼링 내려찍기 | 파이프 낙뢰 내려찍기 + 건틀릿 연쇄 충돌 | 띄운 적을 내려찍으면 옆으로 날아가 다른 적을 친다 |
| 집중 탄막 | 권총 난사 + 사슬 소용돌이 | 소용돌이에 묶인 적에게 탄막이 꺾여 모인다 |
| 그물 베기 | 파이프 섬광 베기 + 사슬 헤이즈 그물 | 섬광 베기가 그물로 이어진 적 전부를 벤다 |
| 반격 탄막 | 건틀릿 역류 + 권총 탄막 회피 | 반격 성공 순간 원형 탄막 |
| 폭주 붕괴 | 건틀릿 헤이즈 붕괴 + 게이지 위험 시너지 | 위험 구간 완충 강타가 오버로드 없이 오버로드급 폭발 |

### 나오는 규칙
- 카드 3장: **가진 갈래 ×3**, 들고 있는 무기(파이프·두 번째 칸)의 갈래 ×2, 공통 ×1, 안 든 무기 갈래 ×0.2. 진화·합성은 조건이 되면 한 장 자리를 우선 차지(희귀·전설 테두리).
- 셋 중 하나는 늘 아직 없는 갈래(빌드를 바꿀 여지).
- 두 번째 무기를 바꾸면 그 무기 증강은 남되 효과는 꺼지고, 다시 들면 켜진다.

### 화면
- 증강 카드: 갈래 문양·색, "진화까지 1개" 표시, 진화·합성 카드는 테두리 희귀·전설(이미 있는 카드 틀 3종).
- 일시정지 '이번 판': 갈래별로 묶어 보여 준다.

## 3. 이펙트·연출 (v6에서 이어짐)
- 전투 이펙트 다시 그림: 점묘 없는 단색 3단계 + 첫 프레임 흰색, 초승달 궤적·줄기·고리·사각 파편. pixelfx는 구성만 참고(코드·결과물은 쓰지 않는다).
- **규칙 변경 제안**: 빛·이펙트 층만 반투명·더하기 섞기 허용(블룸·빛 웅덩이). 캐릭터·타일·배경은 알파 0/255 유지.
- 조명(광원 빛 웅덩이, 깜빡임, 림 라이트), 물 반사(위아래 뒤집어 옅게), 연출 순간 카메라 줌(화면 밖 그림판에 그려 확대).
- 진화·합성마다 이펙트가 다르다(위 표).

## 4. 보스·적
- 보스 3종: 크래셔(그림 완료) 패턴을 더 화려하게(망치 충격파 연쇄, 페이즈 전환 연출), 아크·헤이즈 심장 새 디자인(PixelLab).
- 적 움직임·AI 다듬기: 가속·감속, 방향 전환 지연, 예고 → 공격 → 빈틈(회수) 리듬을 분명하게, 무리 지어 겹치지 않게 간격, 피격 반응(넉백·경직) 일관.
