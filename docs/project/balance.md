### 읽는 법과 한계
- 시험장은 평평하고 적이 모두 플레이어에게 몰려온다. 실제 방은 층·발판이 있어 적이 흩어지고, 플레이어는 점프·E 강화·증강을 쓴다. 숫자는 **방끼리, 무기끼리 비교**하는 데 쓰고 절대값은 사용자 플레이로 본다.
- 건틀릿 봇은 게이지가 낮으면 철파이프로 바꿔 채운다(게이지 33% 넘을 때 다시 든다). 짧은 싸움에서는 거의 철파이프로 싸우므로 건틀릿 자체의 약함으로 읽지 않는다.
- 사슬은 관문(간수)에 특히 강하다(잃은 체력 3.7 vs 철파이프 stand 82). 평평한 곳에서 420px 사거리로 거리를 두는 이점이 크다. 실제 관문 방(arena_05)에서도 그런지 사용자 플레이로 볼 것.
- `--meta max`(정비사 강화 모두 최대, 최대 체력 150): 구역 1 큰 방 승률이 stand 기준 85% → 100%. 영구 성장이 체감될 만큼 효과가 있다.

- **제안**: 구역 3만 7무리(`BIG_ROOM_PACKS`를 구역별 딕셔너리로). 구역 3 적(결정 기사·망령)이 단단해서 서툰 플레이 승률이 71%로 다른 구역보다 15%p 낮다. 구역 3은 큰 방이 하나뿐이라 영향은 작다. 플레이해 보고 정한다.

### 도전방 시간 `12초 + 적 하나당 4.5초`
시뮬레이션에서 이긴 판은 **모두** 시간 안에 들어왔다(가장 느린 건틀릿도 제한의 절반 정도). 여러 공식의 통과율:

| 방 | 지금 12+4.5n | 10+3.5n | 8+3n | 6+2.5n |
|---|---|---|---|---|
| 구역 1 전투방 (건틀릿) | 95% | 95% | 88% | 78% |
| 구역 3 전투방 (건틀릿) | 98% | 98% | 90% | 68% |
| 구역 3 큰 방 (건틀릿) | 70% | 62% | 52% | 20% |
| 그 밖의 무기·방 | 승률과 같다 | 거의 같다 | 조금 낮다 | 낮다 |

- 실제 방은 층을 오르내리며 적을 찾아야 해서 시험장보다 오래 걸린다. 그 여유를 생각하면 **지금 값 유지를 추천**한다.
- 플레이해서 도전이 '공짜'로 느껴지면 `10 + 3.5n`(시뮬레이션 통과율이 거의 그대로이면서 여유가 4분의 3)으로.
- 참고: 쥐는 3마리 무리라 적 수가 많이 잡혀 구역 1 시간이 더 넉넉하다(전투방 평균 6.2마리 → 39.9초).

### 장치 피해 (증기 10, 레이저 8)
- 증기 분출 10: 투척병(10)과 같고 0.7초 예고가 있다. 가시(15)보다 약하다. **유지.**
- 레이저 8: 천천히 훑고 한 번 닿으면 1초 쉰다. **유지.**
- **확인할 것**: 레이저의 `LASER_GAUGE = 6`은 `take_hit`의 기본 손실(-5)에 더해져 **최종 게이지는 +1%**다. 주석("오르는 게이지")과 결정 기록("게이지가 오른다")의 뜻이 최종 +6%라면 `projectile._gauge_delta(6)`처럼 넘겨야 한다(아크 탄막이 그렇게 한다). 간수(+15 → 최종 +10)와 같은 방식으로 본다면 지금이 맞다. 규칙 해석이라 고치지 않았다.

### 구역 하나에 드는 체력 (참고)
보통 전투방 수 × 잃은 체력 + 큰 방 + 끝 싸움으로 더하면, `dodge` 봇이 구역 1에서 160~350, 구역 3에서 110~245를 잃는다. 회복은 시작 체력 100 + 물약 2병(70) + 회복 보상(25, 방 보상의 약 20%) + 정비방 물약이다.
봇은 점프·E·증강을 쓰지 않아 실제보다 훨씬 많이 맞지만, 구역 1이 처음 하는 사람에게 버거울 수 있다는 신호로 본다.
- **제안**: 사용자가 구역 1을 몇 판 해 보고 어렵다면 `POTION_START` 2 → 3, 또는 `REWARD_HEAL` 25 → 30. 초보자 모드를 켜면 같은 봇이 구역 1에서 80~220을 잃는다(약 40% 감소).

### 제안 검증: 구역 통판 시뮬레이션 (`--run`, 조정자 요청)
위의 표는 싸움마다 체력 100에서 시작한다. 실제 판처럼 **체력·게이지를 이어서** 한 구역을 끝 싸움까지 싸우게 했다
(방 순서는 시드로 섞고, 전투방 보상의 20%는 회복, 싸움이 끝났을 때 체력 45 아래면 물약을 마신다. 정비방 물약 구입·증강·E·점프는 치지 않는다).
칸은 구역 통과율(%)이고 순서는 철파이프 / 쌍권총 / 건틀릿 / 사슬, 시드 20개, `dodge` 봇.

| 조건 | 구역 1 | 구역 2 | 구역 3 |
|---|---|---|---|
| 지금 값 | 0 / 0 / 35 / 0 | 0 / 5 / 15 / 15 | 0 / 10 / 30 / 55 |
| 물약 3병 (`POTION_START` 3) | 0 / 5 / 45 / 5 | 0 / 15 / 15 / 20 | 5 / 25 / 50 / 85 |
| 회복 보상 30 (`REWARD_HEAL` 30) | 0 / 0 / 40 / 5 | 0 / 10 / 10 / 15 | 0 / 10 / 45 / 50 |
| 물약 3 + 회복 30 | 0 / 5 / 45 / 5 | 0 / 15 / 10 / 25 | 0 / 25 / 60 / 85 |
| 정비사 강화 모두 최대 (`--meta max`) | 0 / 0 / 60 / 0 | 0 / 0 / 50 / 15 | 5 / 15 / 80 / 80 |
| **초보자 모드** | 10 / 55 / 90 / 35 | 30 / 95 / 60 / 95 | 55 / 80 / 90 / 100 |
| 초보자 모드 + 물약 3 | 25 / 90 / 90 / 90 | 70 / 100 / 85 / 100 | 75 / 80 / 100 / 100 |
| 초보자 모드 + 강화 최대 | 15 / 65 / 95 / 70 | 50 / 100 / 100 / 100 | 75 / 90 / 100 / 100 |

`stand` 봇은 지금 값에서 모든 칸이 0%이고, 초보자 모드에서 0~55%다.

읽는 법:
- 봇은 사람보다 훨씬 서툴다(점프·E·증강·지형 없음, 적이 한꺼번에 몰려온다). 그래서 **지금 값 0%는 '게임이 못 깰 만큼 어렵다'는 뜻이 아니다.** 조건끼리 비교하는 데만 쓴다.
- 물약 3병은 회복 보상 30보다 효과가 크다(같은 체력이라도 위기 때 쓸 수 있어서). 둘을 같이 올려도 물약 3병과 거의 같다.
- 정비사 강화 최대(체력 +50 등)는 통과율을 조금 올린다. 영구 성장만으로 어려움이 풀리지는 않는다.
- 초보자 모드가 가장 큰 손잡이다. 쌍권총·사슬은 구역 2·3에서 거의 다 깬다.
- **철파이프가 모든 조건에서 가장 낮다.** 근접이라 무리 싸움에서 가장 많이 맞는다(보통 전투방 dodge 기준 잃은 체력 35 vs 사슬 24·건틀릿 14). 시작 무기라 처음 하는 사람이 가장 오래 드는 무기다.

제안 (모두 플레이로 확인한 뒤):
1. 처음 하는 사람이 구역 1에서 자주 죽는다면 먼저 초보자 모드를 권한다(처음 안내판에 한 줄). 수치는 그대로 둔다.
2. 보통 난이도도 어렵다면 `POTION_START` 2 → 3 (회복 보상 30보다 효과가 크다).
3. 철파이프로 무리 싸움이 버겁다면 철파이프 3타(올려베기)·띄우기의 경직을 늘리는 쪽을 본다(공격력보다 맞는 횟수를 줄이는 쪽). 이번에는 손대지 않았다.

## 추천안으로 정함 (사용자가 바꿀 수 있다)
- 초보자 모드 수치: 받는 피해 ×0.6, 줄어드는 게이지 ×0.6. 기본은 꺼짐. 설정 화면 '피해 숫자'와 '테스트 모드' 사이.
- 초보자 모드가 완화하는 게이지 감소의 범위: 피격·시간 경과·보스 지형 띠. 건틀릿·E 비용과 심장 농도 파동은 그대로.
- 게이지 규칙(0% 사망, 100% 오버로드)과 오버로드 기절 시간은 초보자 모드에서도 그대로(오버로드 체력 피해만 ×0.6).
- 시뮬레이터 구역 시나리오의 전투방 스폰 수 5칸(템플릿이 4~6칸을 쓴다).

## 화면으로 확인하지 못한 것
- 초보자 모드를 켠 실제 플레이 감각(몇 대 맞으면 죽는지, 게이지가 너무 안 내려가 각성에 오래 머무는지).
- 설정 화면은 Xvfb 캡처로 줄 배치만 봤다. 마우스로 칸을 누르는 것과 키보드 이동은 테스트로만 확인.
- 큰 방·도전방·장치 수치는 시뮬레이션뿐이다(위 제안은 모두 플레이로 확인할 것).
- 증기 기둥은 Xvfb 캡처(정지 화면)로만 봤다. 실제 시간으로 움직이는 모습과 소리는 못 봤다.

## 사용자가 로컬에서 볼 순서
1. 설정 → '초보자 모드' 켬 → 구역 1을 한 판. 피해 숫자와 게이지가 덜 내려가는지 본다. 껐을 때와 비교.
2. 초보자 모드를 끄고 구역 1 큰 방·도전방을 해 보고, 위 제안(구역 3 큰 방 7무리, 물약 3병)이 필요한지 정한다.
3. 레이저에 닿았을 때 게이지가 +1%인 것이 의도인지 정한다.
4. 구역 2 공장 방에서 증기 분출구: 굵은 김 기둥이 끊기지 않고 솟는지, 너무 하얘서 주인공·적을 가리지 않는지.
