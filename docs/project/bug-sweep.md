# 2026-11-26 자동 플레이 점검: 오늘 넣은 기능

대상: 이펙트 교체, 증강 뽑기 손질, 저주 증강, 실루엣 컷인·궁극기 각성, 보스 등장 정적·체력바·크래셔 착지, 빛줄기, 강화 교체기, 등불·보스 막타 줌, 보스 카드.
새 기능은 넣지 않았다. 도구는 `tools/fuzz_play.py`(실제 창, 모니터 2, 설정·저장은 임시 폴더).

## 돌린 범위
- **65판, 572,548프레임** (판마다 8,000~40,000프레임, 시드 101~103·201~203·301~304·401~403·501). 그중 플레이 화면 258,630프레임, 등장씬 186,811프레임, 일시정지·설정·키 설정 23만 프레임, 증강 창 10,214, NPC 창 11,368, 사망·탈출 화면 9,562, 크레딧 29,912. 새 판 시작 385번.
- 구역: 슬럼(문지기)·공장(크래셔)·탑(아크 -> 헤이즈 심장)을 `FOCUS`로 각각, 그리고 자유 경로(은신처·연습장·NPC 창 포함). `BOSS_KILL`, `P_DIE`로 처치·사망 경로를 넓혔다.
- 이번에 도구에 더한 선택지(게임 코드가 아니라 도구 쪽. 사용법은 파일 머리말):
  - `CURSE=1` 저주 카드가 늘 섞이고 여섯 종을 차례로 건다. 걸린 횟수: 무뎌진 손 86, 메마름 79, 좁아진 한계 73, 굳은 손 42, 유리 몸 66, 시한폭탄 58. 좁아진 한계 중 한계 강화 61번·헤이즈 샘 61번, 굳은 손 중 교체 시도 134번·판 도중 무기 얻기 78번, 시한폭탄 중 오버로드 26번(사망 화면 -> 은신처), 방을 깬 것으로 세어 풀기 126번.
  - `AWAKEN=1` 궁극기 각성 + 강화 3단계를 자주 채움(814번), 컷인 15,741프레임, 컷인 중 피격 310번.
  - `CUTKILL=1` 컷인 도중 보스 처치 77번, 페이즈 문턱 바로 아래로 깎기(다음 갱신에 페이즈 컷인) 17번.
  - `SKIP=1` 등장씬 동안 Enter·Space·Esc 1,248번(넘기기 연타, 등장씬 중 일시정지). `RESEEN=1` 처음 만난 등장씬(크래셔 착지)을 다시 보게 함.
  - `ENH=1`·`ONE_WEAPON=1` 강화 1~3단계 교체기, 무기 하나로 시작해 판 도중 둘째 무기 얻기(45번).
  - `OFFER`·`FEW=1` 증강 창을 자주 열고 카드를 0~3장으로(0장 26, 1장 30, 2장 31, 3장 268번).
  - 늘 검사: 떠돌이 죄수 '증강 거래'가 내놓는 카드에 저주가 없는지, 컷인이 2초 넘게 도는지, 막타 줌이 실제 시간 2초 넘게 남는지, 등장씬 밖에서 HUD가 숨거나 음악 정적이 5초 넘게 남는지, 게이지 한계가 노멀 구간 아래로 내려가는지, 굳은 손인데 교체되는지. **모두 0번.**
  - `SHOTS=<폴더>`로 장면 242장을 남겨 눈으로 봤다(컷인·등장씬·저주 카드·저주 표시·막타 줌·사망 화면·NPC 창·일시정지).
