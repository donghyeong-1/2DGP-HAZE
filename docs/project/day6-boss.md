# 스레드 1 `v8/day6-boss` 보고서: 보스 등장씬과 대사

브랜치: `claude/project-thread-x0ifu3` (인계서의 `v8/day6-boss` 대신 클라우드 세션이 정해 준 브랜치 이름을 썼다. 내용은 같다)

## 여기까지 했다
- `src/boss_intro.py` 새 파일: 보스방에 들어서면 위아래 검은 띠 → 카메라가 보스로 이동 → 대사 2~3줄(글자가 차례로 찍힘) → 이름 띠(기존 `zone_card` 보스 카드) → 카메라가 플레이어로 돌아오며 싸움 시작.
  - 등장씬 동안 게임이 멈춘다(world를 갱신하지 않으므로 입력·피해 모두 막힌다). 누르던 키는 떼고, 끝날 때 실제로 눌린 키만 다시 누른다.
  - Enter·Space로 넘긴다(카메라 이동 → 대사로, 찍히는 줄 → 다 보이기, 다 보인 줄 → 다음 줄, 이름 띠 → 바로 닫기). 게임패드 A·X·Y도 넘기기.
  - 두 번째 만남부터 짧게: 다시 만난 대사 한 줄, 이동·이름 띠도 짧게.
  - 헤이즈 심장은 다 내려온 뒤에 등장씬. 내려올 때 떠오르던 '헤이즈 심장' 글자는 이름 띠가 대신한다.
  - 페이즈 전환·처치 때 한 줄(자막, 게임은 멈추지 않음). 플레이어가 보스방에서 쓰러지면 보스가 한 줄.
  - `config.BOSS_INTRO = False`면 예전 동작(이름 띠만 바로).
- 고친 곳: `src/boss.py`·`src/ark.py`·`src/heart.py`(한 줄 대사 호출), `src/zone_card.py`(`open_boss`·`close_now`·`holding`, 등장씬이 켜져 있으면 스스로 뜨지 않음),
  `src/camera.py`(`look_at`), `src/play_mode.py`(멈춤·입력 거르기·객체 추가), `src/gamepad.py`(멈춤 중 넘기기), `src/ui.py`(등장씬 중 HUD 숨김),
  `src/config.py` 맨 끝 블록(`BOSS_INTRO`), `tests/test_boss_intro.py`(18개), `tests/test_zone_card.py`(보스 카드 테스트를 등장씬에 맞춤).
- 테스트: 전체 689개 통과(기준 671 + 새 18), `test_pixel_assets.py` 8개 통과.

## 추천안으로 정함
- "같은 판에서 두 번째부터는 짧게": 한 판 안에서 같은 보스를 두 번 만날 일이 없어서(보스방은 잠기고 죽으면 판이 끝난다) **게임을 켠 뒤 두 번째 만남부터**로 했다. 판이 바뀌어도 기억하고, 게임을 껐다 켜면 처음부터 다시 길게 본다. 저장 파일에 남기려면 `meta.py`(스레드 2 영역)가 병합된 뒤 붙인다.
- 보스 대사는 캐릭터의 말이라 화면 설명 문장의 '~합니다' 규칙 밖으로 두었다(반말·하오체).
- 마우스 클릭은 넘기기로 치지 않는다(공격하며 들어오던 클릭으로 대사가 날아가지 않게). 등장씬 시작 0.3초 안의 누름도 무시한다.
- 크래셔 자막 이름은 기획서의 `제4구역장 크래셔`로 했다(이름 띠와 체력 바는 그대로 '크래셔').
- 대사(전부 `src/boss_intro.py`의 `LINES`):
  - 크래셔: "슬럼 쥐새끼가 공장까지 기어 올라왔군." / "4구역 용광로는 아무도 못 지나간다." / "녹여서 철골에 박아 주마, N-09." · 분노 "뜨겁나? 용광로는 이제 막 달아올랐다!" · 처치 "용광로가... 식는다..."
  - 아크: "실험체 N-09. 탈출 시도, 처음이 아니지." / "헤이즈는 내가 정한 만큼만 흐른다." / "기록을 끝내자. 이 탑이 네 마지막 감방이다." · 2페이즈 "농도 조정. 네 게이지는 내 손에 있다." · 3페이즈 "제어 해제. 탑의 헤이즈를 전부 연다." · 처치 "이 껍데기로는... 부족하군."
  - 헤이즈 심장: "이것이 진짜 모습이다. 탑의 심장, 헤이즈의 근원." / "네가 들이마신 헤이즈는 전부 내 숨이었다." / "돌아와라, N-09. 너도 처음부터 나의 일부였다." · 처치 "숨이... 멎는다... 안개가... 걷힌다..."

## 로컬에서 볼 순서
1. 테스트 모드(F9)로 스테이지 2 보스방 → 크래셔 등장씬 전체, Enter·Space 넘기기.
2. 한 번 더 F9 → 짧은 등장씬.
3. 체력을 절반 아래로 → 분노 한 줄, 처치 → 처치 한 줄.
4. 스테이지 3 보스방 → 아크 등장씬, 페이즈 2·3 한 줄, 처치 뒤 헤이즈 심장이 내려와 등장씬.
