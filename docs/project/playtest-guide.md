## 1. PR #4 보스·문지기 (7분)
보고서: `docs/project/day6-boss.md`. 캡처: `shots/day6-boss/` 안 `gatekeeper.png`, `crasher_intro.png`, `ark_heart_intro.png`, `impact_frame_boss.png`
- **주의**: 등장씬은 **게임을 켠 뒤 그 보스를 처음 만날 때만 길게** 나온다. 두 번째부터는 짧다. 긴 것을 다시 보려면 게임을 껐다 켠다.
1. 테스트 모드 켬 → 판 시작 → **F6 → F9**: 문지기 관문. 검은 띠 → 카메라 이동 → 대사 3줄 → 이름 띠. Enter·Space로 넘기기도 눌러 본다.
   - 볼 것: 카메라 속도, 대사 길이, 검은 띠(112px)가 바닥을 가리지 않는지.
2. 문지기와 싸우기: 방패 돌진을 벽으로 유도해 비틀거림(0.9초)이 칠 만한 빈틈인지, 체력 절반에서 증원 호출(폐인·사냥개)이 너무 버거운지. 문지기는 간수 그림을 크게 구운 임시 그림이다(도트가 다른 캐릭터보다 굵다).
3. **E 강화 일격**을 아무 적에게 한 번, 문지기 **막타**를 한 번: 흑백 임팩트 프레임(2프레임)이 뜨는지, 거슬리지 않는지. 설정 '번쩍임 줄이기'를 켜면 안 뜬다.
4. **F7 → F9**(크래셔), **F8 → F9**(아크): 등장씬, 페이즈 전환 한 줄, 처치 한 줄. 아크를 쓰러뜨리면 헤이즈 심장이 내려온 뒤 등장씬.

## 2. PR #2 합성 증강·버그 훑기 (6분)
보고서: `docs/project/day7-augments.md`, `docs/project/bug-sweep.md`. 캡처: `day7-augments/` 안 `끌어모아한방.png`, `집중탄막.png`, `반격탄막.png`, `각인폭풍.png`, `검기.png`, `쳐내기.png`, `일시정지_형태목록.png`
1. 은신처 **무기 걸이**에서 시작 무기 둘을 고른다. 합성마다 필요한 무기가 다르다:
   - 끌어모아 한 방: 사슬(소용돌이) + 건틀릿(헤이즈 붕괴)
   - 집중 탄막: 쌍권총(난사) + 사슬(소용돌이)
   - 반격 탄막: 건틀릿(역류) + 쌍권총(탄막 회피)
   - 볼링 내려찍기: 철파이프(낙뢰 내려찍기) + 건틀릿(연쇄 충돌)
   - 각인 폭풍·교체 연무: 서로 다른 무기의 진화 둘
2. 연습장 → F → '증강 넣기·빼기'에서 **합성 카드와 그 조건인 진화 증강 둘을 함께** 넣는다(위 괄호 안 이름이 진화 증강이다. 각인 폭풍·교체 연무는 무기가 다른 진화 아무거나 둘). '적 불러내기'로 적 셋쯤 세우고 써 본다.
   - 볼 것: 볼링 내려찍기에서 날아가는 거리, 교체 연무의 교체기 칸 막대(0.5초), 검기의 굵기(캡처에서 덩어리처럼 보였다), 쳐 내기 소리.
3. 판 안에서 Esc: '이번 판' 카드 맨 위 **무기 형태** 금색 줄(형태를 얻은 판에서). 형태는 구역 첫 전투방 보상이나, #3이 병합되면 황금방에서도 얻는다.
4. 버그 훑기는 튕김을 막는 수정이라 따로 해 볼 것이 없다. 연습 메뉴 '효과음 듣기'에서 G·B·X를 눌러 꺼지지 않으면 된다.

## 3. PR #1 밸런스·초보자 모드·증기 (5분)
보고서: `docs/project/balance.md`. 캡처: `balance/` 안 `options_easy.png`, `steam_jet_ingame.png`, `steam_jet_timeline.png`
1. 설정 → **'초보자 모드'** 켬(피해 숫자와 테스트 모드 사이). **테스트 모드는 끄고** 구역 1 전투방 두세 개: 받는 피해 숫자가 작아졌는지, 게이지가 덜 내려가는지. 끄고 같은 방을 한 번 더 해서 비교.
   - 정할 것: 초보자 모드에서 게이지가 너무 안 내려가 각성 구간에 오래 머무는지.
2. 테스트 모드 켬 → **F7**(공장) → 전투방의 **증기 분출구**: 다시 구운 굵은 김 기둥, 0.7초 예고가 보이는지.
3. 보고서 끝 "제안"을 보고 정한다: 구역 3 큰 방 무리 수, 시작 물약 2 → 3, 레이저에 닿았을 때 게이지 +1%가 의도인지.

## 4. PR #3 NPC 대사·화면 밖 화살표·황금방 형태 (7분)
보고서: `docs/project/v8-day6-npc.md`. 캡처: `npc-dialogue/` 안 `npc_first_archivist.png`, `npc_long_keeper.png`, `drifter_greet.png`, `ending_clear.png`, `gold_form.png`, `gold_crop.png`, `event_door.png`, 그리고 `playtest/offscreen_big.png`
1. **NPC 대사**: 처음 보는 대사를 보려면 새 저장이 필요하다. 저장을 잠시 옮긴다: `~/.haze_save.json` → 다른 이름(끝나면 되돌린다). 은신처에서 정비사·보관인·기록관 창을 열어 오른쪽 위 한마디와 표정.
   - **테스트 모드를 끄고** 슬럼에서 한 번 쓰러진다(가시나 적 무리에 서 있기). 은신처로 돌아와 다시 열면 보관인은 '슬럼', 정비사는 든 무기 이야기를 한다.
   - 볼 것: 한마디가 제목 줄과 겹치지 않는지, 말맛.
2. **화면 밖 적 화살표**: 테스트 모드 켬 → F6 → 큰 방(들어가면 화면이 옆이나 위로 한 화면 더 이어지는 방, 구역마다 한두 개)에 들어가 적에게서 멀리 떨어진다. 화면 가장자리에 빨간 화살표가 적 쪽을 가리키고 0.8초마다 잠깐 흐려진다. 작은 방에서는 적이 셋 이하로 남았을 때만 뜬다.
   - 볼 것: 싸우는 중에 깜빡임이 거슬리는지, 화살표 크기(32px)가 너무 작은지.
3. **이벤트 방 문 이름**: 미니맵의 '?' 방 옆 방에서 문 위에 '헤이즈 샘' 같은 이름(이제 문 위에 뜬다. 전에는 오른쪽 문 이름이 무기 HUD와 겹쳤다). 이벤트 방 안의 떠돌이 죄수에게 가까이 가면 인사말.
4. **황금방 형태 진열대**: 판 중에 황금방에 들르면 셋 중 하나가 '철파이프 · 중량 타격'처럼 들고 있는 무기의 형태(금색 별 아이콘)다. 황금방은 구역의 전투방을 다 깨야 열려서 따로 찾아가기는 길다. 지나가다 볼 수 있으면 본다.
5. **탈출 화면 한 줄**과 **크레딧**: 테스트 모드로 F8 → F9 → 아크·심장을 쓰러뜨리면 탈출 화면 아래 한 줄, 이어서 크레딧의 'AI 도구'에 PixelLab·Gemini 줄.
6. 다 보면 옮겨 둔 `~/.haze_save.json`을 되돌린다.
