# 게임 안 글자 전수 검토 (2026-11-25, Claude 프로젝트, 대기열 5번)

기준: `docs/DECISIONS.md` 2026-11-25 화면 글자 기준(사용자 검토)과 `docs/NEXT_SESSION.md` 5절.
선택·확인·변경·교체를 쓰고, 설명 문장은 "~합니다"로 끝낸다. 수치 줄은 그대로 둔다. 끼워 넣은 이름 뒤에 조사를 붙이지 않는다. 카드는 "증강"으로 부르고, 적 이름은 `killers.py`, 무기 이름은 철파이프·쌍권총·건틀릿·사슬을 쓴다.

## 방법
`src/*.py`에서 한글이 든 문자열 상수와 f-문자열을 모두 뽑아 973개를 봤다(docstring은 뺐다). 뽑는 스크립트는 저장소 밖에 두었다.
아래 규칙에 걸리는 것만 다시 손으로 봤다.
- 고르다·골라, 바꾸다·바꿔, 변이, 식칼, '결정'을 확인 뜻으로 쓴 곳, 카드
- 문장인데 "~니다"가 아닌 말로 끝나는 것(~다, ~음, ~게 등)
- `{이름}` 뒤에 을·를·이·가·은·는·와·과·로가 붙은 것
- 아래 안내줄(footer)의 Enter 이름

개발자만 보는 글(방 검사 `room.py`·`room_check.py`, 오류 기록)과 효과음 검토 창(`sfx_mode.py`, 사용자 전용 도구)은 제외했다.

## 결과 요약
11/25 검토 뒤라 대부분 규칙을 지킨다. 고를 말(고르다·바꾸기·변이·식칼·카드)이 화면에 남은 곳은 아래 고친 것 말고는 없다. 안내줄의 Enter는 모두 '확인'이거나 그 창의 동작 이름(맡기기·듣기·실행·변경)이다.
