## 한 일
- `src/meta.py`: 판이 끝날 때 직전 판 기록 `state['last']`와 쓰러뜨린 보스 `state['beaten']`를 남긴다(`record_run`, `finish_run(player, escaped, zone, ark_down)`). 저장을 읽을 때 값이 이상하면 그 값만 기본값.
- `data/dialogue.py`(새 파일): 대사 글. NPC마다 (조건, 대사, 표정). 머리말에 조건 표.
- `src/talk.py`(새 파일): 기록 -> 조건 이름(tags), 조건 -> 대사(pick). 사망 원인 글을 오버로드·고갈·보스·가시·장치로 나눈다.
- `src/npc_mode.py`: 창 오른쪽 위(제목 줄, 결정 수 아래)에 한마디. 아직 아무것도 하지 않았으면 초상화 표정이 대사의 표정(정비사 씩 웃음, 보관인 걱정, 기록관 놀람).
- `src/events.py`: 떠돌이 죄수에게 가까이 가면 'F 거래' 위에 인사말(판마다 셋 중 하나).
- `src/ending_mode.py`: 끝난 구역과 아크를 눕혔는지 넘김, 탈출 화면에 탈출 뒤 한 줄(처음 / 두 번째부터, 판 기록 아래 y=430).
- `src/killers.py`: 장치의 사망 원인 이름(증기 분출구, 감시 레이저). 전에는 '알 수 없음'이었다.
- `tests/test_dialogue.py`(새 파일, 18개): 기록, 첫 처치는 한 번만, 연속 사망, 깨진 저장, 원인 분류, **모든 조건이 실제 판 기록에서 걸리는지**, **모든 대사가 나올 수 있는지**, 위 조건 우선, 판마다 돌아감, 길이(30자)·용어, 창의 한마디·표정, 엔딩, 죄수 인사.

## 조건과 우선순위 (위가 먼저)
- 정비사: 처음 → 첫 탈출 → 탈출 → 아크 첫 처치 → 크래셔 첫 처치 → 관문 첫 통과 → 오버로드 → 고갈 → 든 무기(무기마다 2줄) → 늘
- 보관인: 처음 → 첫 탈출 → 탈출 → 같은 구역 세 번 → 슬럼 입구 → 가시·장치 → 탑 → 공장 → 슬럼(구역마다 2줄) → 늘
- 기록관: 처음 → 첫 탈출 → 아크·크래셔·관문 첫 처치 → 심장·아크·크래셔에게 쓰러짐 → 오버로드 → 고갈 → 적 40 이상 → 늘(2줄)

- 탈출 화면의 한 줄(y=430)이 판 기록 카드(아래 끝 약 y=504)와 '맡긴 물건'(y=470), 안내(y=380) 사이에 잘 들어가는지.

## 추천안으로 정한 것
- 쓰러뜨린 보스를 따로 세지 않고 도달한 구역으로 정했다(stage.py는 스레드 1이 고치므로 건드리지 않으려고).
- 관문 첫 통과도 '보스를 처음 잡았다'로 친다. 심장 첫 처치는 탈출과 같은 순간이라 따로 대사를 두지 않고 '첫 탈출'이 맡는다.
- 무기 대사는 쓰러질 때(탈출할 때) **들고 있던** 무기로 고른다.
- 기록 항목이 생기기 전의 저장(판 수 > 0, 기록 없음)에는 '처음' 인사를 하지 않고 '늘' 대사를 한다.
- 주인공은 대사에서 'N-09'로만 부른다('화이트'는 임시 이름이라 쓰지 않았다).
- 기록관의 이야기 줄 셋(STORY)은 그대로 두었다.

## 사용자가 로컬에서 볼 순서
1. 새 저장으로 은신처 → 세 NPC 창을 열어 '처음' 대사와 위치.

3. 테스트 모드로 공장까지 가서 쓰러진 뒤(정비사·기록관 '관문'), 같은 구역 세 번(보관인 걱정 표정).
4. 이벤트 방의 떠돌이 죄수 인사말, 탈출 화면의 한 줄.
