# 1차 발표 대본 (1분 30초)

슬라이드 순서대로 읽는다. 실제로 소리 내어 읽어 90초가 되는지 확인하고, 길면 문장을 줄인다.

**1.** 안녕하세요. 제가 만들 게임은 헤이즈입니다.  (24자)

**2.** 마우스로 조준하고 방을 돌파하는 순수 창작 횡스크롤 액션 로그라이크입니다.  (41자)

**3.** 헤이즈로 뒤덮인 네뷸라 교도소에서 죄수 화이트는 총감시관을 쓰러뜨리고 탈출하려 합니다.  (48자)

**4.** 방의 적을 모두 처치하면 문이 열립니다. 정비방에서 성장하며 보스까지 돌파합니다.  (45자)

**5.** 이동과 2단 점프, 저장되는 대시, 마우스 조준 공격을 사용하며 무기 두 개를 교체합니다.  (50자)

**6.** 핵심은 헤이즈 게이지입니다. 시간이 지나면 줄고 공격하면 오릅니다. 각성 구간에서는 강하지만, 가득 차면 폭발하고 0퍼센트가 되면 즉시 사망합니다.  (82자)

**7.** 예를 들어 92퍼센트일 때 E키를 누르면 67퍼센트로 낮아지고 무기가 8초간 강화됩니다. 보스와 안개가 짙은 방은 게이지를 위아래로 흔듭니다.  (79자)

**8.** 목표 규모는 스테이지 세 개, 일반 적 네 종류와 보스 두 종류, 무기 네 종류입니다.  (48자)

**9.** 발표 후 약 5주 동안 개발합니다. 게이지를 먼저 구현하고 지연되면 스테이지와 무기를 줄입니다.  (53자)

**10.** 캐릭터는 AI로 제작하고 에셋의 출처를 기록합니다. 감사합니다.  (35자)

총 505자 (공백 포함, 슬라이드별 문장 합계). 분당 320자 가정 시 약 94.7초. 실제 낭독과 전환 시간을 확인한다.
