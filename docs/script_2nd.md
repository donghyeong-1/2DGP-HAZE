# 2차 발표 영상 대본 (1분 30초)

가이드: 프로젝트 진행 상황 발표 + 게임 데모 실행. 글자가 또렷하고 음성이 잘 들려야 한다. **녹화 뒤 반드시 직접 재생해서 들어본다.**

## 구성과 시간 (합계 90초)

| 시간 | 화면 | 내용 |
|---|---|---|
| 0:00~0:15 | PPT 1장 | 게임 설명 |
| 0:15~0:40 | PPT 2장 | 계획 대비 진행 상황, 기획 변경 |
| 0:40~1:30 | 게임 데모 | 아래 데모 순서 |

## 슬라이드 낭독

**1장.** 헤이즈는 게이지가 0퍼센트면 죽고 100퍼센트면 폭발하는 횡스크롤 액션 로그라이크입니다. 화면보다 큰 방을 탐험하고, 마우스로 조준해 적을 모두 처치하면 문이 열립니다.  (94자)

**2장.** 계획한 이동, 게이지, 조준 공격, 적 두 종은 완료했고, 3주차 계획도 앞당겨 방 열두 개와 황금방, 정비방, 보스방을 만들었습니다. 이번 주에는 타수 증가와 특수 공격, 방마다 다른 맵 테마, 캐릭터 애니메이션을 더했습니다.  (127자)

## 데모 순서와 낭독 (게임 화면 녹화, 1920×1080)

실행: `python src/main.py` → 타이틀에서 아무 키.

1. 방 1(허브): 큰 방을 카메라가 따라가는 모습. 마우스 방향으로 겨누어 좌클릭 (위·대각선으로 휘둘러지는 철파이프 자세와 궤적, 맞은 자리의 충격선, 게이지가 높을 때(F1 후 F3으로 올림) 한 번에 여러 번 맞는 숫자).
   - 낭독: 큰 방에서 마우스로 겨누어 파이프를 휘두르면 충격선이 퍼지고, 게이지가 높을수록 타수가 늘어납니다.  (55자)
2. 대시(Shift)하면 지나온 길을 베고 잔상이 남는다. 얇은 발판 위에서 마우스를 아래에 두고 대시하면 발판을 뚫고 내려간다. 적을 모두 처치하면 문이 열리고, 문 색(노랑 황금방, 파랑 정비방, 빨강 보스)을 보여 준다.
   - 낭독: 대시는 지나온 길을 한 번에 베고, 아래로 겨누면 발판을 뚫습니다. 적을 모두 처치하면 갈 방을 고릅니다.  (59자)
3. 황금방(허브 → 교차로 → 위 문): F로 아이템 하나 획득, 정비방(허브 아래 문): 조각으로 구매. 그 뒤 F1 후 F3을 계속 눌러 게이지를 100%로 만들어 오버로드(화면 번쩍임, 기절 연출)를 보여 준다.
   - 낭독: 황금방과 정비방에서 성장하고, 게이지가 가득 차면 화면이 번쩍이며 기절합니다.  (43자)
4. 보스 방(허브 오른쪽 길 끝): E로 강화한 뒤 크래셔와 싸운다. 충격파는 점프, 돌진은 대시로 피한다. 처치하면 탈출 화면, 일부러 죽으면 사망 화면(쓰러지는 동작 뒤에 넘어감).
   - 낭독: E로 강화하면 한 번의 공격이 크게 터지고, 마지막은 보스 크래셔입니다. 감사합니다.  (47자)

총 낭독 425자 (공백 포함). 분당 320자 가정 시 약 80초 + 데모 조작 시간. 길면 데모 낭독 문장을 줄이고, 짧으면 방 2 설명을 늘린다.
