# 2차 발표 영상 대본 (1분 30초)

가이드: 프로젝트 진행 상황 발표 + 게임 데모 실행. 글자가 또렷하고 음성이 잘 들려야 한다. **녹화 뒤 반드시 직접 재생해서 들어본다.**

## 구성과 시간 (합계 90초)

| 시간 | 화면 | 내용 |
|---|---|---|
| 0:00~0:15 | PPT 1장 | 게임 설명 |
| 0:15~0:40 | PPT 2장 | 계획 대비 진행 상황, 기획 변경 |
| 0:40~1:30 | 게임 데모 | 아래 데모 순서 |

## 슬라이드 낭독

**1장.** 헤이즈는 게이지가 0퍼센트면 죽고 100퍼센트면 폭발하는 횡스크롤 액션 로그라이크입니다. 화면보다 큰 방을 탐험하고, 마우스로 조준해 적을 모두 처치하면 문이 열립니다.  (94자)

**2장.** 계획했던 이동과 게이지, 조준 공격, 적 두 종은 모두 구현했고, 방 이동은 앞당겨 위아래 좌우로 고르는 열두 개 방 맵과 황금방, 정비방, 보스방까지 만들었습니다. 남은 것은 무기와 적, 보스 아크, 스테이지 둘, 걷기 애니메이션입니다. 데모를 보겠습니다.  (144자)

## 데모 순서와 낭독 (게임 화면 녹화, 1920×1080)

실행: `python src/main.py` → 타이틀에서 아무 키.

1. 방 1(허브): 큰 방을 카메라가 따라가는 모습. 아래·위층 적을 마우스 방향으로 겨누어 좌클릭 (위·대각선으로 휘둘러지는 궤적, 3타째는 주황색 큰 궤적).
   - 낭독: 카메라가 따라가는 큰 방입니다. 문이 잠겨 있고, 마우스로 겨누는 방향으로 파이프가 휘둘러집니다. 위층 적도 위로 겨누어 칠 수 있습니다.  (77자)
2. 적을 모두 처치하면 문이 열린다. 문 색(노랑 황금방, 파랑 정비방, 빨강 보스)을 보여 주고 위·아래 문으로도 이동해 선택지를 보여 준다. 대시는 무적이고 잔상이 남는다.
   - 낭독: 적을 모두 처치하면 문이 열리고, 위아래 좌우 중 갈 방을 고릅니다. 노랑 문은 황금방, 파랑은 정비방, 빨강은 보스입니다.  (69자)
3. 황금방(허브 → 교차로 → 위 문): F로 아이템 하나 획득. 정비방(허브 아래 문): 조각으로 구매. 미니맵이 채워지는 것을 보여 준다.
   - 낭독: 황금방에서 아이템 하나를 고르고, 정비방에서는 모은 조각으로 업그레이드를 삽니다. 돌수록 강해지지만 게이지는 계속 줄어듭니다.  (70자)
4. 보스 방(허브 오른쪽 길 끝): `F1` 후 `F3`으로 게이지를 올려 E로 강화한 뒤 크래셔와 싸운다. 충격파는 점프, 돌진은 대시로 피한다. 처치하면 '탈출 성공' 화면.
   - 낭독: 게이지가 높을 때 E를 누르면 게이지를 쓰고 무기가 강해지며, 처치한 적은 폭발합니다. 마지막은 보스 크래셔입니다. 감사합니다.  (71자)

총 낭독 525자 (공백 포함). 분당 320자 가정 시 약 98초 + 데모 조작 시간. 길면 데모 낭독 문장을 줄이고, 짧으면 방 2 설명을 늘린다.
