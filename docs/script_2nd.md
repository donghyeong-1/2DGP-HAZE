# 2차 발표 영상 대본 (1분 30초)

가이드: 프로젝트 진행 상황 발표 + 게임 데모 실행. 글자가 또렷하고 음성이 잘 들려야 한다. **녹화 뒤 반드시 직접 재생해서 들어본다.**

## 구성과 시간 (합계 90초)

| 시간 | 화면 | 내용 |
|---|---|---|
| 0:00~0:15 | PPT 1장 | 게임 설명 |
| 0:15~0:40 | PPT 2장 | 계획 대비 진행 상황, 기획 변경 |
| 0:40~1:30 | 게임 데모 | 아래 데모 순서 |

## 슬라이드 낭독

**1장.** 헤이즈는 게이지가 0퍼센트면 죽고 100퍼센트면 폭발하는 횡스크롤 액션 로그라이크입니다. 마우스로 조준해 방의 적을 모두 처치하면 문이 열립니다.  (81자)

**2장.** 계획했던 이동과 게이지, 마우스 조준 공격, 적 두 종을 모두 구현했고, 방 잠금과 이동, 미니맵, E 강화는 일정을 앞당겼습니다. 변경은 화면을 1920 곱하기 1080으로 키운 것뿐입니다. 남은 것은 무기, 적, 보스, 업그레이드입니다. 그럼 데모를 보겠습니다.  (148자)

## 데모 순서와 낭독 (게임 화면 녹화, 1920×1080)

실행: `python src/main.py` → 타이틀에서 아무 키.

1. 방 1: 가까운 슬럼에게 다가가 좌클릭으로 3연타(3타째 큰 화면 흔들림). 투척병은 없고 슬럼 2마리.
   - 낭독: 첫 방입니다. 적이 있어서 문이 잠겨 있습니다. 마우스로 겨누고 좌클릭으로 파이프를 휘두르면, 맞힐 때마다 게이지가 오릅니다.  (70자)
2. Shift(또는 우클릭)로 대시해 공격을 피하며 잔상을 보여 준다. 적을 모두 처치 → '방 클리어' 문구, 문이 청록색으로 열림.
   - 낭독: 대시를 하면 잔상이 남고 무적입니다. 적을 모두 처치하면 문이 열리고 다음 방으로 갑니다.  (50자)
3. 오른쪽 문으로 이동 → 방 2(투척병이 던지는 고철은 점프나 대시로 피한다). 미니맵이 채워지는 것을 보여 준다.
   - 낭독: 마지막 방은 헤이즈가 짙어 게이지가 계속 차오릅니다. 게이지가 높을 때 E를 누르면 게이지를 쓰고 무기가 강해지며, 처치한 적은 폭발합니다.  (78자)
4. 방 3(고농도 방): 게이지가 올라가 있을 때(50% 이상 권장) E를 눌러 강화 → 적을 처치해 폭발 장면. 필요하면 `F1` 후 `F3`으로 게이지를 올려 둔다.
   - 낭독: 이번 주 목표는 여기까지입니다. 감사합니다.  (24자)

총 낭독 451자 (공백 포함). 분당 320자 가정 시 약 85초 + 데모 조작 시간. 길면 데모 낭독 문장을 줄이고, 짧으면 방 2 설명을 늘린다.
